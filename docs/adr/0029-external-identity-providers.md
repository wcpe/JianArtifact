# ADR-0029：外部身份源（OIDC / LDAP）接入与会话签发

## 状态

已接受（0.11.0，待用户验收）。

## 背景

0.2.0 起身份只来自本地 `user` 表（argon2id 口令 + 无状态 JWT 会话，见 [ADR-0008](0008-auth-session-model.md)）。企业环境下账号由 IdP / 目录服务统一管理，两处维护账号既增成本也增风险（离职遗留账号、口令策略不一致）。FR-34 / FR-35 要求接入 OIDC 与 LDAP 登录。

关键约束：

- **零外部依赖默认形态**（NFR-01）：不得为会话引入外部存储或联合注销依赖；
- **明文凭据不落库、不进日志**（NFR-06、AC-05）；
- **永不锁死**（ADR-0008 的恢复口径）：外部身份源不可用时，本地管理员必须仍能登录；
- 下游（ACL、审计、冻结窗口、协议鉴权、OpenAPI 契约）已有稳定的会话表达，不应因引入外部身份源而分叉。

## 决策

1. **外部身份源只是"新增登录来源"，会话仍是本地 JWT**（ADR-0008 不变）：外部登录成功后由 `domain.AuthService` 这**单一签发点**签发与本地登录完全相同的会话，下游不感知来源差异。
2. **用户绑定与供给**：`external_subject` 命中即绑定 → 未命中按用户名绑定既有未绑定用户 → 仍无则**建号**（角色固定 `user`、不设本地口令、记录 `auth_source`）；可选白名单（域名 / 用户名）作为收紧手段。`status=disabled` 与 `web_login_disabled` 对两种来源一律生效。
3. **数据模型**：`user` 表新增 `auth_source`（`local` / `oidc` / `ldap`，缺省 `local`）与 `external_subject`（部分唯一索引，空串不参与唯一性）；**不回填**既有行（缺省即 `local`）。
4. **外部凭据只从环境变量解析**：OIDC client secret、LDAP bind 密码沿用 `JIAN_UPSTREAM_CREDENTIAL_<名称>` 的运行时解析范式，不落库、不进日志、不写进审计。
5. **本地管理员永不锁死**：启用外部身份源不关闭本地口令登录通道；网页自举与 `admin reset` 不受影响。
6. **LDAP 证书校验默认严格**：支持 `ldaps://` 与 StartTLS，仅允许配置自定义 CA；**不提供"跳过证书校验"开关**（对齐 FR-131 防静默降级口径）。
7. **协议实现依赖** `github.com/coreos/go-oidc/v3`、`golang.org/x/oauth2`、`github.com/go-ldap/ldap/v3`（均纯 Go、无 CGO，符合架构不变量）。

## 理由

- **复用本地会话**：会话表达是下游一切判定的输入；让外部登录产出与本地登录同构的 JWT，ACL / 审计 / 冻结 / 契约全部零改动，避免"两套会话语义"长期分叉。
- **JIT 建号 + ACL 兜底**：外部用户的权限仍完全由 ACL 决定（建号本身不授予任何仓库可见性），上手成本低而边界清晰；白名单给需要收紧的部署留出口。
- **凭据只走环境变量**：与既有上游凭据、TLS 私钥、JWT 密钥同口径——配置文件与数据库都不成为凭据的落脚点。
- **本地通道不关**：IdP 或目录是新的外部依赖，若允许它成为唯一登录方式，一次目录故障即等于全站锁死；保留本地管理员是成本最低的兜底。
- **不提供跳过证书校验**：一旦提供，"图省事"的部署会静默降级到明文信任；与项目既有的"防静默降级"取向一致。

## 后果

- **正面**：企业身份即登录即可用；离职在目录侧停用后**无法再次登录**；凭据与令牌不入库不进日志；下游零改动。
- **负面 / 约束**：
  - 外部身份源的可用性影响"其来源用户"的登录（本地管理员与本地账号不受影响）；
  - **已签发的 JWT 在过期前仍然有效**——禁用（无论本地还是目录侧）只对新登录即刻生效，与本地账号既有语义一致；如需"即时踢出"需另立增量（缩短 TTL 或引入会话版本号），不在本期范围；
  - 目录组 → 角色 / ACL 映射、单点登出（SLO）、多 IdP 均未涉及，属 FR-36 或后续增量；
  - 新增三个第三方依赖，需纳入依赖与许可清单同步。

## 备选方案

- **引入联合注销 / 外部会话存储**：撤销即时且与 IdP 会话联动，但违背零外部依赖默认形态，落选。
- **按用户名匹配绑定（不用 `sub`）**：实现更简单，但用户名可被 IdP 侧改名，改名即产生新账号或抢占风险；`sub` 是 OIDC 保证稳定的标识，故以其为准。
- **把 IdP / 目录口令同步写入本地口令哈希**：可复用全部本地登录路径，但等于把外部口令复制进本库，违背最小泄漏面，落选。
- **LDAP 提供"跳过证书校验"开关**：便于自签环境上手，但会把安全降级做成一次性配置项，落选（改用自定义 CA 解决自签场景）。
