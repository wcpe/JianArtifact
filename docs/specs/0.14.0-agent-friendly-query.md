# 功能规格：SPA 回退白名单与远程查询 CLI

覆盖 PRD FR-178（SPA 回退收窄为路由白名单）与 FR-179（`jianartifact query` 远程查询子命令）。两条需求服务于同一目标：让 AI agent 与自动化在与实例交互时「错误请求快速失败」，不再收到伪装成数据的 HTML 或静默忽略的参数。

## 1. 背景与目标

- `mountStatic` 的 `NoRoute` 此前只对协议前缀拒绝回退，任意路径返回 200 + `index.html`：agent 按路径后缀把 HTML 当 XML/JSON 解析，报出不存在的版本号。
- CLI 全为本地运维命令，无远程客户端能力；agent 手写 URL 时参数名猜错会被服务端静默忽略（`prefix` 写成 `path` 返回根目录且无报错）。

目标：非前端路由一律 404 + JSON；`query` 子命令封装请求构造、校验 Content-Type、结构化输出，不新增发布物、不引入 GraphQL（守 ADR-0004 单一契约与 NFR-01）。

## 2. 需求（要什么）

- **FR-178**：首段白名单内的前端路由回退 `index.html`；白名单外一律 404 + `{"error":{"code":"not_found"}}`。白名单集中为单个变量并注明来源 `apps/web/src/app/router.tsx`；新增前端顶层路由须同步登记。协议前缀检查保留作双保险，静态资源查找先于白名单判定，缓存策略不变。
- **FR-179**：`jianartifact query` 子命令：`repos` / `ls` / `find` / `get` / `usage` / `api`。收到 `text/html` 立即非零退出并提示正确基址形态；URL 与查询串全由 CLI 用 `net/url` 转义；输出支持 `--json` 选字段与 `--jq`（gojq，纯 Go）。连接设置按「命令行 > 环境变量 > `~/.config/jianartifact/config.json` > 默认」合并。

## 3. 设计（怎么做）

### 3.1 SPA 回退白名单（FR-178）

`internal/httpserver/server.go` 的 `spaRoutePrefixes` 首段集合；`NoRoute` 判定顺序：协议前缀拒绝 → 静态资源命中 → 首段白名单回退 → 404 JSON。

### 3.2 远程查询客户端（FR-179）

`cmd/jianartifact/query.go`：`queryClient` 复用默认 `http.Transport` 连接池；`endpoint()` 把已转义段写入 `url.URL.RawPath`（写 `Path` 会被二次转义）；响应先查 Content-Type 再查状态码。凭据安全边界：

- 配置文件令牌只属于该文件登记的服务端：`--server` / `JIAN_SERVER` 指向另一实例时不得沿用，避免凭据交给第三方。
- 携带令牌时拒绝非回环的明文 HTTP 目标；回环地址（localhost / 127.x / ::1）保留明文便利。
- 空响应体（204/202）视为已受理并报告状态码（`--json`/`--jq` 模式输出 `{"status":<code>}`），不按 JSON 解析失败谎报；非 JSON 响应体（如 `/metrics` 文本）仅在默认模式原样透传，`--json`/`--jq` 模式要求 JSON 响应、否则报错；超过 16 MiB 的响应报错而不输出截断内容。

### 3.3 退出码

0 成功；2 用法错误（缺参数、基址不合法、path 不以 `/` 开头）；1 请求失败或响应校验失败。

## 4. 任务拆分

- `internal/httpserver`：`spaRoutePrefixes` + `NoRoute` 白名单判定 + 全路由枚举测试（含 `/security` 登记回归）。
- `cmd/jianartifact`：query 子命令族 + `query_test.go` 全部用 `httptest` 假服务端。

## 5. 验收标准

- `/api/v1/nonexistent`、`/org/x/maven-metadata.xml`、`/llms.txt` 返回 404 JSON；白名单路由返回 200 HTML；静态资源与协议前缀行为不变。
- `query` 各子命令对假服务端验证：HTML 响应非零退出并提示基址形态；401/403/404 翻译成可操作提示；`--jq` / `--json` 字段筛选生效；切换 `--server` 不带出配置文件令牌；带令牌拒绝明文 HTTP（回环除外）；204 空体与文本响应不误报失败。
