# 功能规格：0.2.0 管理端 Web

> 状态：已交付@v0.2.0　·　关联 PRD：FR-11（M1，P1）　·　依赖：FR-06–10 后端核心已交付、api/openapi.yaml 契约冻结

## 1. 背景与目标

在 0.2.0 认证授权核心（FR-06–10）与冻结的 `api/openapi.yaml` 管理面契约之上，交付管理端 Web 全页面：登录/自举、仪表盘、用户、访问令牌、仓库与仓库 ACL。开发态脱离后端，由 devmock 的 MSW 双端拦截层提供内存态数据，保证前端可独立开发、测试与验收。参见 ADR-0003（Mantine 7）、ADR-0005（单二进制内嵌）。

## 2. 需求（要什么）

- **FR-11 管理端 web 全页面**：React 18 + Mantine 7 + i18next（中文）+ react-router v6，覆盖 6 类视图：
  - 登录 / 自举：据 `/api/v1/status` 的 `userCount` 自动切换——空库走自举创建首个管理员，否则走登录。
  - 仪表盘：实例状态概览（版本 / 就绪 / 初始化 / 用户数 / 迁移版本）。
  - 用户：列表 + 新建 + 改角色/状态 + 重置口令 + 删除。
  - 访问令牌：列表 + 新建（明文仅回显一次）+ 吊销。
  - 仓库：列表 + 新建（格式/类型/可见性）+ 切换可见性 + 删除 + 进入 ACL。
  - 仓库 ACL：条目（用户 ID + 权限）增删改，整表 PUT 保存。
- 范围内：`apps/web`（页面/路由/鉴权上下文/typed API client/i18n/MSW dev 接入）、`packages/ui`（Mantine 主题/Provider + 共享状态态与页头组件）、`packages/devmock`（MSW 双端拦截：内存态 store + http handlers + browser/node 入口）。
- 不做：wiki 验收站（FR-12，下一轮）；多语言英文资源（预留结构，暂只中文）；服务端真实鉴权联调（本轮对 devmock 完成）。

## 3. 设计（怎么做）

- **契约优先**：`api/openapi.yaml` 唯一真源 → devmock `openapi-typescript` 生成 `schema.gen.ts`；web 经子路径 `@jianartifact/devmock/schema` 仅做类型级 import（构建期擦除，不把 devmock 打进生产包）。
- **typed API client**：`api/client.ts` 统一 baseURL(`/api/v1`)、`Bearer` 注入、JSON 解析与 `ApiError`（承载 `error.code`/`message`/status）；`api/endpoints.ts` 按契约封装全部端点；令牌存 `localStorage`。
- **鉴权上下文**：`AuthProvider` 持有用户与令牌，`login`/`bootstrap`/`logout`；后端无 `/me`，故持久化用户快照，刷新免重登；`RequireAuth` 守卫受保护路由。
- **状态与体验**：`useAsync` 钩子封装加载/数据/错误/重拉；`AsyncBoundary` 统一渲染共享 `LoadingState`/`ErrorState`/`ForbiddenState`（`packages/ui`）；错误通过 Mantine `notifications` 反馈。
- **共享 UI**：`packages/ui` 提供 `AppProvider`（MantineProvider + 主题）、`PageHeader`、四类状态态组件与设计令牌；不反向依赖 `apps/*`。
- **控制台外壳（沿用旧项目视觉，对齐 ADR-0003）**：`app/AppLayout.tsx` 用 `AppShell layout="alt"` 可折叠分段侧栏（品牌 logo + 版本号置顶、浏览/管理分段、收起态仅图标 + Tooltip/aria-label、footer 折叠按钮、固定 max-width 居中内容区）；密度令牌 `theme/density.ts` 与 `global.css`（`scrollbar-gutter: stable`）集中约定。配色对齐旧项目：主色 Mantine 原生蓝 + 品牌蓝 `#228be6` 仅用于 logo + 色彩模式 `auto`。外壳仅接线 0.2.0 已有页面，页眉搜索/通知/更新徽标等待各自 FR 落地再补。
- **开发态 Mock**：`packages/devmock` 内存态 `store` + `msw.ts` handlers（路径 `*/` 前缀通配 origin，双端复用）；浏览器 `worker`（`src/mocks/enableMocking.ts` 仅 `import.meta.env.DEV` 启动）、Node `server`（vitest 集成测试）。MSW 钉 `2.7.6`。
- **交付**：`vite build` 产 `apps/web/dist`，经 `go:embed`（`apps/server/web`）内嵌单二进制；生产构建不含 MSW/devmock。

## 5. 验收标准

- **AC-07（对齐 FR-11）**：登录/自举据实例状态切换；登录成功写入会话令牌；受保护页面携带令牌拉取数据。
- **AC-08（对齐 FR-11）**：用户/令牌/仓库/ACL 各视图 CRUD 对 devmock 走通，列表随操作回显。
- **AC-09（对齐契约门）**：web 经生成的 `schema.gen.ts` 类型消费契约；devmock↔OpenAPI 契约测试通过。
- 未鉴权受保护列表进入错误态、令牌明文仅回显一次、空库进入自举——均有组件/集成测试佐证（devmock 12 + ui 6 + web 9）。
