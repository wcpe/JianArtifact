# 功能规格：0.4.0 Nexus drop-in URL 兼容与公开读入口

> 状态：开发中（核心能力已随 0.3.0 协议层落地，迁移域收尾后整体验收）　·　关联 PRD：FR-24a　·　分支：feature/nexus-dropin

## 1. 背景与目标

JianArtifact 定位为 Nexus OSS 的**可替换品**（见 PRD §1、NFR-09）。迁移域（FR-20~23）解决"把数据搬过来"，本规格解决"搬完之后客户端怎么切换"——即：**Nexus 3 的原生客户端（curl/mvn/npm 等）在只改 host、不改 path 的前提下，能否对本实例透明工作**，并把这一能力在运维文档与管理端 UX 中显式暴露，降低切换成本。属 M1（P1），是 MVP 替换闭环的收尾。

核心事实（已实现，本规格予以正式登记与验收固化）：

- 协议路径与 Nexus 3 默认形态一致：Raw/Maven 走 `/repository/{repo}/{artifactPath}`，npm 走 `/npm/{repo}/…`。
- `visibility=public` 的仓库协议层匿名 GET/HEAD 可读；浏览器公开预览页 `/p/{name}` 仅对 public 仓开放。
- group 仓库跨成员有序聚合读；Maven `maven-metadata.xml` 跨成员合并 versions。
- 管理端仓库列表暴露「访问 URL」「成员/上游」列与一键复制。

## 2. 需求（要什么）

- **路径兼容（Nexus drop-in）**：Raw/Maven 制品经 `{base}/repository/{repoName}/{artifactPath}` 存取，与 Nexus 3 同形；客户端改 host 不改 path 即可对接。npm 因 Nexus npm 宿主路径差异，须单独改 registry 为 `{base}/npm/{repoName}/`（已知差异，文档标注）。
- **公开读入口**：`visibility=public` 的 hosted/proxy/group 仓库，协议层允许**匿名** GET/HEAD（无需 Basic/Token）；`private` 仓库匿名返回 401，需 `Authorization: Bearer <jat_…>` 或 Basic（API Token 作 password）。group/proxy 的写（PUT/DELETE）固定 409，仅 hosted 可写。
- **group 聚合**：`type=group` 按 `members` 有序聚合读，首个命中返回；Maven `maven-metadata.xml` 跨成员合并 versions 并重算 latest/release/lastUpdated。
- **管理端 UX**：仓库列表显示每仓「访问 URL」（按 format 拼 `/repository/{repo}` 或 `/npm/{repo}/`，可一键复制）与「成员/上游」（group 显成员、proxy 显 remoteUrl、hosted 显 —）。
- **运维文档**：OPERATIONS 给出 Nexus `maven-public` 替换步骤（同名 hosted 占名时的两种处理方案）、匿名读配置、抽样校验命令。
- 范围内：路径/鉴权/group 的既有协议行为登记与验收固化、管理端 UX、运维文档。
- 不做（范围外）：
  - 不为本实例的 npm 增加与 Nexus 完全一致的 npm 宿主路径（保持 `/npm/{repo}/`，差异以文档说明）。
  - 不自动处理"迁移把 Nexus group 名落成 hosted"的占名冲突（提供手动方案 A/B，见 §6）。
  - 不做 Nexus REST API 兼容（管理面仅本实例 `/api/v1`）。
  - 不做 cutover 自动化（cutover 检查清单与最终增量扫描属 FR-23）。

## 3. 设计（怎么做）

本规格以**既有实现登记 + 验收固化**为主，无新协议代码改动；UX 与文档增量已在未发布版本完成。

- **协议层（已实现，登记）**：
  - `internal/protocol/router.go`：`RegisterRoutes` 挂 `/repository/:repo/*artifactPath`（GET/HEAD/PUT/DELETE），由 `Dispatcher` 按仓库 format 分派（maven→MavenHandler，其余→RawHandler）。
  - `internal/protocol/npm.go`：`RegisterNpmRoutes` 挂 `/npm/:repo/*rest`（packument/tarball/publish）。
  - 鉴权：`authenticator.Optional()` 允许匿名进入，handler 内 `authorize(read)` 对 public 仓放行、private 仓未认证返回 401。
- **管理端 UX（未发布版本已完成）**：
  - `apps/web/src/pages/RepositoriesPage.tsx`：列表新增「访问 URL」列（`Code` + `CopyButton`，按 format 拼路径）、「成员/上游」列、type 着色 Badge。
- **运维文档（已完成）**：`docs/OPERATIONS.md` §1.1.6 Nexus URL drop-in 说明（路径形态、匿名读、group 聚合、同名 group 冲突处理、真机示例）。
- **真机验收（已完成）**：`124.222.29.78` 实例迁移 Nexus 后，`maven-public`（hosted）设 public、另建 `maven-all`（group, members=maven-releases,maven-snapshots,maven-public），匿名 `curl` 拉 jar 与 maven-metadata.xml 通过。

## 5. 验收标准

- **路径兼容**：匿名 `curl -fsS {base}/repository/{publicRepo}/{artifactPath}` 返回 200 且字节与迁移源一致；`curl -I` 同。
- **公开读边界**：public 仓匿名 GET/HEAD 成功；private 仓匿名 GET 返回 401，带合法 Bearer/Basic 后成功。
- **写权限**：hosted 仓 PUT 成功；group/proxy 仓 PUT/DELETE 返回 409。
- **group 聚合**：public group 仓匿名 GET `maven-metadata.xml` 返回合并后的 versions（去重、latest/release 正确）；匿名 GET 制品按成员有序命中。
- **管理端 UX**：仓库列表每行显示访问 URL 且可复制；group 行显示成员 Badge，proxy 行显示 remoteUrl，hosted 行显示 —。
- **运维**：OPERATIONS §1.1.6 给出 Nexus `maven-public` 替换的两种方案与抽样命令。
- **实机·须用户确认**：从真实 Nexus 切换 host 后，`mvn`/`curl` 原生客户端经 public group 仓匿名解析与拉取成功（对齐 PRD AC-01/AC-02 的切换维度）。
- `gofmt`/`go vet`/`go test ./...`/`CGO_ENABLED=0 go build ./...` 全绿；前端 typecheck/lint/test 全绿（本规格无新增代码改动时回归不破即可）。

## 6. 风险 / 待定

- **npm 路径差异**：本实例 npm 走 `/npm/{repo}/`，与 Nexus npm 宿主路径不同；npm 客户端必须改 registry，不能仅改 host。以文档明确，不做路径兼容改造。
- **同名 group 与迁移 hosted 冲突**：若迁移把 Nexus 的 group 名（如 `maven-public`）落成了 hosted，严格同名 group 需先删占名 hosted（CASCADE 清 asset 元数据）再重建。提供方案 A（保留数据另建 group + 反代/改客户端）与方案 B（删 hosted 重建同名 group）；**不自动处理**，由运维按场景选择。是否在管理端提供"重命名/转换仓库类型"向导留待后续评估。
- **剪贴板 API 受安全上下文限制**：管理端「复制 URL」按钮依赖 `navigator.clipboard`，HTTP（非安全上下文）下被浏览器禁用；HTTPS 部署后自然可用，不做降级 polyfill。
- **反代基址**：usage 片段与 npm tarball 重写依赖 `X-Forwarded-Proto`/`Host` 透传（见 ADR-0011），反代部署须配置。
