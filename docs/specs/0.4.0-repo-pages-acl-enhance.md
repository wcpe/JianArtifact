# 功能规格：0.4.0 仓库页面与权限完善（FR-25a~e，对标旧项目）

> 状态：开发中　·　关联 PRD：FR-25a/b/c/d/e　·　分支：feature/repo-pages-acl-enhance

## 1. 背景与目标

从 Nexus 迁移后，管理端仓库浏览、制品详情、权限配置需要达到「直接正常使用」的 MVP 终态体验。本规格对标旧 Rust 项目（`D:\RustProjects\JianArtifact-old`）的前端实现，补齐：ACL 用户下拉框、制品多校验和（SHA-256/SHA-1/MD5）登记与展示、后端 HTML 目录索引页、仓库统计、详情页 Tab 布局。属 M1（P1）。

## 2. 需求（要什么）

### FR-25a · ACL 页面用户下拉框
- ACL 编辑页用户 ID 从手填 `NumberInput` 改为可搜索 `Select`（从 `listUsers` 自动加载）
- 已有 ACL 条目展示用户名而非数字 ID
- 不改后端 ACL API

### FR-25b · 制品详情多校验和 + 依赖坐标
- `asset` 表扩展 `sha1`、`md5` 列（0005 迁移）；上传/迁移写入时计算并存储（不现算）
- 前端详情面板展示 SHA-256/SHA-1/MD5（各带复制）+ Maven GAV 多格式依赖坐标（8 种，下拉切换）+ HTML View 外链 + 下载按钮

### FR-25c · 后端 HTML 目录索引页
- `GET /repository/{repo}/{dir}/`（尾斜杠 + `Accept: text/html`/浏览器 UA）渲染 HTML 目录列表
- 子目录/文件链接、面包屑导航、内联 CSS
- public 仓匿名可访问，private 需认证

### FR-25d · 仓库列表统计
- `Repository` 响应增加 `artifactCount` + `totalSize` 字段
- 后端用 GROUP BY 一次聚合避免 N+1
- 前端列表新增「制品数」「总大小」两列

### FR-25e · 详情页 Tab 布局
- 详情页改为 Tab 布局（浏览/配置/ACL）
- 管理员可见配置与 ACL Tab；非管理员仅浏览
- 文件树固定高度独立滚动

## 5. 验收标准

- ACL 页面用户选择为可搜索下拉框；保存后 ACL 生效
- 制品详情展示 SHA-256/SHA-1/MD5（从 DB 读取）；Maven 制品可切换 8 种坐标格式
- 浏览器访问仓库目录 URL 返回 HTML 目录列表；public 仓匿名可访问
- 仓库列表显示制品数与总大小
- 详情页 Tab 切换正常；浏览 Tab 左树右详情独立滚动
- `gofmt`/`go vet`/`go test ./...`/`CGO_ENABLED=0 go build ./...` 全绿；前端 typecheck/lint/test 全绿
- **实机·须用户确认**：从 Nexus 迁移后管理端浏览/权限/详情体验完整可用

## 6. 风险 / 待定

- **0005 迁移**：已有 asset 的 sha1/md5 为空字符串，旧制品不会回填（需重新上传或后续补 GC 扫描任务）
- **HTML 目录索引与 SPA 路由冲突**：需确认 Gin 通配 `*artifactPath` 对尾斜杠的处理不与前端路由冲突
- **OpenAPI 契约重生**：FR-25b/d 改了 schema，需同步重生 Go + TS 代码
