# Spec：开源协议页（FR-72）

> 状态：已实现 ｜ 版本：0.6.0 ｜ 分类：feat ｜ 优先级：P2
> 关联：PRD §4.2 FR-72；参考截图（搜索框 + 分段表格：软件包/版本/协议徽章/作者）

## 1. 目标与范围

在 Web UI 提供「开源协议」页面，展示本项目**Go 后端依赖**与**前端 npm 依赖**的完整清单
（包名、版本、协议、作者），并在侧边栏左下角提供入口。匿名与登录用户均可访问。

**不做**（YAGNI）：

- 不做协议全文弹窗/行展开（首版只列协议标识，点包名跳源站）
- 不做后端 API（纯前端静态数据，构建时生成）
- 不做传递依赖树可视化

## 2. 数据来源与生成（构建管线）

### 2.1 生成脚本 `scripts/generate-licenses.mjs`（Node，新增）

一次生成两段数据，输出到 `apps/web/src/generated/licenses.json`（**入库提交**）：

```jsonc
{
  "generatedAt": "2026-07-24T00:00:00Z",
  "go": [
    { "name": "github.com/gin-gonic/gin", "version": "v1.12.0", "license": "MIT", "author": "gin-gonic" }
  ],
  "npm": [
    { "name": "@mantine/core", "version": "7.17.8", "license": "MIT", "author": "Vitaly Rtishchev" }
  ]
}
```

- **npm 段**：执行 `corepack pnpm licenses list --json --prod`（workspace 根），归并去重
  （同名多版本各留一行）；`author` 取 pnpm 输出的 author 字段，缺省 `—`。
- **Go 段**：在 `apps/server` 执行 `go list -m -json all` 取直接+间接模块清单
  （排除主模块自身）；对每个模块在 `GOMODCACHE`（本仓 `.gomodcache/`）定位
  `LICENSE* / COPYING* / NOTICE` 文件，用 SPDX 关键词启发式识别协议
  （MIT / Apache-2.0 / BSD-2-Clause / BSD-3-Clause / MPL-2.0 / ISC / Unlicense / LGPL / GPL），
  识别失败标 `Unknown`；`author` 取模块路径第二段（如 `gin-gonic`）。
- **软失败**：`go` 或 `pnpm` 不可用时，警告并**保留现有 JSON**（不中断构建）。

### 2.2 管线接入

- `apps/web/package.json` 新增 `"licenses:gen": "node ../../scripts/generate-licenses.mjs"`；
  `build` 脚本串入生成步骤（`node .../generate-licenses.mjs && tsc && vite build`，
  pnpm 默认不执行 pre/post 钩子）→ 满足「依赖变更后重新构建自动更新清单」。
- 生成文件入库：dev 模式与测试直接静态 import，无需先跑脚本。

## 3. 前端页面与入口

### 3.1 路由

- `apps/web/src/app/router.tsx`：`AppLayout` 内新增**公开路由** `/licenses`
  （与 `/repositories` 同级，无 `RequireAuth`）。

### 3.2 页面 `apps/web/src/pages/LicensesPage.tsx`（新增）

- 顶部：页标题 + 搜索框（`TextInput` + `IconSearch`），按包名/协议/作者即时过滤两段表格。
- 两个分段卡片（对齐参考截图分段样式）：
  - 「后端依赖 · Go (N)」
  - 「前端依赖 · npm (N)」
  - N 为过滤后行数。
- 表格列：**软件包**（外链：Go → `https://pkg.go.dev/<name>`，npm → `https://www.npmjs.com/package/<name>`）｜
  **版本**｜**协议**（`Badge` variant="light"，Unknown 用 gray）｜**作者**。
- 数据源：`import licenses from "../generated/licenses.json"`（构建期打包，匿名可访问）。
- 空过滤结果显示 `EmptyState`。

### 3.3 侧边栏入口（`AppLayout.tsx` 左下 footer）

- footer 区（现仅折叠按钮）左侧加「开源协议」入口：
  - 展开态：`UnstyledButton` + `IconLicense` + 小字「开源协议」，靠左；折叠按钮维持靠右。
  - 折叠态：仅图标，Tooltip 显示文案，与折叠按钮纵向排列。
- 登录/匿名两种侧边栏**均显示**；点击 `navigate("/licenses")`。

### 3.4 i18n

`licenses.title`（开源协议）/ `licenses.searchPlaceholder` / `licenses.goSection` /
`licenses.npmSection` / `licenses.colPackage` / `licenses.colVersion` / `licenses.colLicense` /
`licenses.colAuthor` / `nav.licenses`，zh/en 双语。

## 4. 测试计划（先行）

1. `test/LicensesPage.test.tsx`：
   - 渲染后两个分段标题可见，且各出现至少一行真实依赖（如 `gin`、`@mantine/core`）；
   - 搜索框输入过滤词后不匹配的行消失、计数更新；
   - 匿名（无 token）渲染不重定向、不弹登录。
2. 脚本冒烟（非 CI 阻断）：本地跑 `licenses:gen` 后 JSON 两段均非空、无 `Unknown` 占比 > 50%。

## 5. 验收标准（对齐 PRD）

- [ ] 侧边栏左下角入口，登录/匿名均可见，点击进入 `/licenses`
- [ ] 页面含搜索框 + Go/npm 两段表格（包名/版本/协议徽章/作者），样式对齐参考截图
- [ ] 依赖变更后 `pnpm build` 自动重新生成清单（prebuild 钩子）
- [ ] 匿名可访问；前端测试绿；typecheck/lint 绿

## 6. 风险与备注

- `.gomodcache` 为仓库本地缓存，脚本依赖其存在；缺失时软失败保留旧 JSON。
- `pnpm licenses` 输出结构以 pnpm 10 实测为准，解析需防御字段缺失。
- 协议识别为启发式，`Unknown` 属可接受结果（页面如实展示）。
