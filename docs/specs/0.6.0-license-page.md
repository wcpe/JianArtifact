# Spec：开源协议页（FR-72）

> 状态：已实现 ｜ 版本：0.6.0 ｜ 分类：feat ｜ 优先级：P2
> 关联：PRD §4.2 FR-72；参考截图（搜索框 + 分段表格：软件包/版本/协议徽章/作者）

## 1. 目标与范围

在 Web UI 提供「开源协议」页面，展示本项目**Go 后端依赖**与**前端 npm 依赖**的完整清单
（包名、版本、协议、作者）。清单属内部合规信息，**仅管理员可见**：数据内嵌到后端二进制，
经 admin 专属端点返回，不打进前端 bundle；匿名/普通用户既无导航入口也拿不到数据。

**不做**（YAGNI）：

- 不做协议全文弹窗/行展开（首版只列协议标识，点包名跳源站）
- 不做传递依赖树可视化
- 不做独立的 RequireAdmin 前端路由守卫（沿用 /users 模式：RequireAuth + 导航 adminOnly + 后端 403 兜底）

## 2. 数据来源与生成（构建管线）

### 2.1 生成脚本 `scripts/generate-licenses.mjs`（Node）

一次生成两段数据，输出到 `apps/server/internal/licenses/licenses.json`（**入库提交**，由后端 `go:embed` 内嵌）：

```jsonc
{
  "generatedAt": "2026-07-24T00:00:00Z",
  "go": [
    { "name": "github.com/gin-gonic/gin", "version": "v1.12.0", "license": "MIT", "author": "gin-gonic" }
  ],
  "npm": [
    { "name": "@mantine/core", "version": "7.17.8", "license": "MIT", "author": "Vitaly Rtishchev" }
  ]
}
```

- **npm 段**：执行 `corepack pnpm licenses list --json --prod`（workspace 根），归并去重
  （同名多版本各留一行）；`author` 取 pnpm 输出的 author 字段，缺省 `—`。
- **Go 段**：在 `apps/server` 执行 `go list -m -json all` 取直接+间接模块清单
  （排除主模块自身）；对每个模块在 `GOMODCACHE`（本仓 `.gomodcache/`）定位
  `LICENSE* / COPYING* / NOTICE` 文件，用 SPDX 关键词启发式识别协议
  （MIT / Apache-2.0 / BSD-2-Clause / BSD-3-Clause / MPL-2.0 / ISC / Unlicense / LGPL / GPL），
  识别失败标 `Unknown`；`author` 取模块路径第二段（如 `gin-gonic`）。
- **软失败**：`go` 或 `pnpm` 不可用时，警告并**保留现有 JSON**（不中断构建）。

### 2.2 管线接入与后端端点

- `apps/web/package.json` 保留 `"licenses:gen"` 与 `build` 前置生成步骤（Makefile 中
  pnpm build 先于 go build，生成结果被同批 go:embed 打进二进制）→ 满足「依赖变更后重新构建自动更新清单」。
- `apps/server/internal/licenses/embed.go`：`//go:embed licenses.json` 内嵌原始字节。
- 新增**非契约端点** `GET /api/v1/licenses`（Optional 鉴权中间件 + handler 内 `requireAdmin`）：
  匿名 401、普通用户 403、管理员 200 直接透传 JSON 字节。

## 3. 前端页面与入口

### 3.1 路由

- `apps/web/src/app/router.tsx`：`/licenses` 位于 `RequireAuth` 内（匿名访问弹登录模态框）。
  导航入口仅 admin 可见；普通用户直达 URL 可进页面但 API 返回 403（由错误态展示）。

### 3.2 页面 `apps/web/src/pages/LicensesPage.tsx`

- 数据源：运行时 `useAsync(getLicenses)` 调 `GET /api/v1/licenses`，`AsyncBoundary` 承载
  加载/错误态（清单数据不进前端 bundle）。
- 顶部：页标题 + 搜索框（`TextInput` + `IconSearch`），按包名/协议/作者即时过滤两段表格。
- 两个分段卡片（对齐参考截图分段样式）：
  - 「后端依赖 · Go (N)」
  - 「前端依赖 · npm (N)」
  - N 为过滤后行数。
- 表格列：**软件包**（外链：Go → `https://pkg.go.dev/<name>`，npm → `https://www.npmjs.com/package/<name>`）｜
  **版本**｜**协议**（`Badge` variant="light"，Unknown 用 gray）｜**作者**。
- 空过滤结果显示 `EmptyState`。

### 3.3 侧边栏入口（`AppLayout.tsx`）

- 入口移入 `NAV_SECTIONS`「管理」段末尾（`IconLicense`，`adminOnly: true`）——与「用户与权限」
  同段，仅管理员可见；匿名/普通用户侧边栏不出现任何协议入口。
- footer 收敛为仅折叠/展开开关（展开态靠右对齐），不再承载功能入口。

### 3.4 i18n

`licenses.title`（开源协议）/ `licenses.searchPlaceholder` / `licenses.goSection` /
`licenses.npmSection` / `licenses.colPackage` / `licenses.colVersion` / `licenses.colLicense` /
`licenses.colAuthor` / `nav.licenses`，zh/en 双语。

## 6. 风险与备注

- `.gomodcache` 为仓库本地缓存，脚本依赖其存在；缺失时软失败保留旧 JSON。
- `pnpm licenses` 输出结构以 pnpm 10 实测为准，解析需防御字段缺失。
- 协议识别为启发式，`Unknown` 属可接受结果（页面如实展示）。
- 普通用户直达 URL 会看到 403 错误态而非页面重定向——接受（与 /users 页同模式）。
