# 功能规格：对端配置 web 可视化 + 自动/手动同步控制

> 状态：草拟　·　关联 PRD：FR-88　·　分支：feature/peer-web-config　·　依赖：FR-83~86、FR-87

## 1. 背景与目标

当前对端配置（URL/令牌）来自环境变量 `JIAN_SYNC_PEER_URL` / `JIAN_SYNC_TOKEN`，web 不可配；且配置对端即自动开始同步（FR-85），不可控。用户要求：

- **连接与同步解耦**：配置对端 ≠ 开始同步；
- **web 可视化配置**对端 URL + 令牌（仅 admin）；
- **可靠开关**控制自动同步；
- **主动同步按钮**（立即同步一次）。

目标（对用户）：在 web「集群」页完成"配置对端 → 打开自动同步（或点立即同步）"的完整闭环，无需改环境变量、无需重启。

## 2. 需求（要什么）

- **对端配置入库**（`setting` 表）：
  - `repl:peer_url`：对端基址（如 `http://103.45.143.199:50020`）；
  - `repl:peer_token`：同步令牌。
  - `JIAN_SYNC_PEER_URL` / `JIAN_SYNC_TOKEN` 环境变量**降级为初始默认值**（首次启动 / 未配置时作为初始对端，可被 web 覆盖）。
- **web「集群」页**（仅 admin）：
  - 对端配置表单：URL + 令牌输入 + 保存（保存即入库，**不自动开始同步**）；
  - 自动同步开关（持久化 `repl:enabled`）；
  - 「立即同步」按钮：调 `POST /api/v1/cluster/sync-now`，无论开关状态立即触发一次同步。
- **调度器改造**（FR-85 的 `ReplicationScheduler`）：
  - 每轮从 `setting` 读对端配置（URL/令牌/开关）；
  - 无对端 → 跳过；有对端 + 开关开 → 轮询同步；开关关 → 跳过；
  - 收到"立即同步"信号（channel）→ 立即执行一次同步（不受开关限制）。
- **web API**（非契约，admin）：
  - `GET /api/v1/cluster`：peerUrl、tokenSet、enabled、watermark、lastSyncAt、lastError；
  - `PUT /api/v1/cluster`：body `{peerUrl?, peerToken?, enabled?}`（可选字段，写入对应 setting）；
  - `POST /api/v1/cluster/sync-now`：触发立即同步，返回同步结果。
- **安全注记**：令牌明文入库（`repl:peer_token`），风险由管理权限（admin-only 端点 + web 页）控制；spec 内明确记录该取舍。

## 3. 设计（怎么做）

### 3.1 setting 键（FR-86 已有 + 新增）

- 已有：`repl:enabled`、`repl:last_sync_at`、`repl:last_error`、`repl:watermark:<peerURL>`。
- 新增：`repl:peer_url`、`repl:peer_token`。

### 3.2 ReplicationScheduler 改造

```
run(ctx):
  for {
    peerURL, token := readPeerConfig()   // setting，无则空
    if peerURL == "" → continue（无对端，跳过）
    if syncEnabled()（repl:enabled）:
      syncOnce(watermark)                  // 轮询自动同步
    select:
      case <-syncNowCh: syncOnce(watermark)  // 手动立即同步（不受开关限制）
      case <-ticker.C: ...
      case <-ctx.Done(): return
  }
```

- `ReplicationClient` 每轮用当前对端配置构造（或支持 `SetPeer(url, token)` 动态更新）——避免每轮重建 client 的开销，改为持有可变 peer 字段。
- `syncOnce` 成功/失败写 `repl:last_sync_at` / `repl:last_error`（FR-86 已有）。

### 3.3 web API

- `api/replication_handlers.go` 扩展：
  - `PutClusterStatus`：支持 `{peerUrl?, peerToken?, enabled?}` 可选字段；写入对应 setting（peer_url/peer_token/enabled）。
  - `PostClusterSyncNow`：向调度器 `syncNowCh` 发信号，等待结果（带超时），返回新状态。
- 调度器句柄注入 `api.Deps`（`Replication *domain.ReplicationService` 已有；新增 `ReplicationScheduler *domain.ReplicationScheduler` 或一个 `SyncNow() error` 接口）。
- main 路由：`POST /api/v1/cluster/sync-now`。

### 3.4 web「集群」页

- ClusterPage 增加：对端配置表单（URL + 令牌 + 保存）、自动同步开关（已有）、「立即同步」按钮。
- devmock 补充 mock。

## 5. 验收标准

- **连接 ≠ 同步**：web 保存对端后，调度器不开始同步（除非开启自动开关或点立即同步）。
- **自动同步开关**：关闭 → 轮询停止；开启 → 下一轮询周期开始同步；持久化（重启保留）。
- **立即同步**：`POST /api/v1/cluster/sync-now` 触发一次同步（无论开关），返回更新后状态（lastSyncAt / lastError）。
- **对端配置持久化**：web 保存后重启保留；环境变量作为初始默认可被覆盖。
- **双向**：两端各自 web 配置对方后，双向同步可用。
- **安全**：对端配置端点仅 admin；令牌不出现在日志；web 表单令牌不回显明文（只显示已配置/未配置）。
- **测试**：调度器（无对端跳过/开关控制/syncNow 触发）、端点（PUT peerUrl/token、POST sync-now、admin 403）、既有测试全绿。
- **实机（用户确认）**：两端 web 配置对端 → 开自动同步 → 双向实时同步；点立即同步手动触发；重启配置保留。

## 6. 风险 / 待定

- **令牌明文入库**：权衡后接受（管理权限保护）；web 表单不回显明文，避免 XSS 泄露。后续可评估加密存储（需密钥管理）。
- **调度器空转**：无对端时每轮读 setting（开销极小）；不做进程级动态启停（保持常驻轮询）。
- **sync-now 超时**：对端不可达时同步可能较久；端点带超时（如 30s），超时返回最近状态而非阻塞。
