# 功能规格：对外基础 URL 配置（public URL）

> 状态：草拟　·　关联 PRD：FR-87　·　分支：feature/public-url　·　依赖：FR-82（npm）、FR-16a（浏览）等 URL 生成功能

## 1. 背景与目标

CDN 回源场景下，源站收到的请求 `Host` 头是**回源 Host**（默认源站地址/IP），而非客户端访问的 CDN 域名。当前所有对外 URL（npm `dist.tarball`、usage 复制片段等）从 `c.Request.Host` 推断，导致：

- 生成的 URL 指向源站地址（如 `http://103.45.143.199:50020/...`），客户端拉取失败；
- **直接暴露源站 IP**（违反"隐藏源站 IP"需求）。

目标（对用户）：显式配置对外域名（`JIAN_PUBLIC_URL`，如 `https://repo.wcpe.top`），所有对外 URL 生成**优先使用它**；未配置时回退当前 Host 推断（兼容非 CDN 部署）。

## 2. 需求（要什么）

- 新增环境变量 `JIAN_PUBLIC_URL`（可选）：对外基础 URL（scheme://host，可含端口；如 `https://repo.wcpe.top`）。
- 所有对外 URL 生成点优先使用它：
  - npm packument `dist.tarball` 重写（`protocol/npm.go requestBaseURL`）；
  - 使用片段拼接（`api/repository_handlers.go apiBaseURL` → 各格式 usage 片段）。
- 未配置 `JIAN_PUBLIC_URL` 时行为不变（当前 `X-Forwarded-Proto` + `c.Request.Host` 推断）。
- 配置后：生成 URL 一律用 public URL，**不泄漏源站地址**。
- 不做：URL 生成的其他场景排查（如 proxy 回源地址）——本期聚焦对外展示 URL。

## 3. 设计（怎么做）

### 3.1 配置

- `config.go`：新增 `EnvPublicURL = "JIAN_PUBLIC_URL"` 与 `Config.PublicURL string`；`Load()` 读环境变量（可空）。

### 3.2 URL 解析器

- 统一一个 resolver：**public URL 优先 → `X-Forwarded-Proto` + `X-Forwarded-Host` 次选 → `c.Request.Host` 兜底**。
- 改造为方法挂在持有配置的结构上，避免包级函数无法访问配置：
  - `protocol.NpmHandler` 增加 `publicURL string` 字段，`requestBaseURL(c)` 改为方法（或传入 resolver）。
  - `api.Handlers` 增加 `publicURL string` 字段，`apiBaseURL(c)` 改为方法。
- wiring / main 装配时注入 `cfg.PublicURL`。

### 3.3 生效点

| 位置                         | 现状                     | 改动                   |
| ---------------------------- | ------------------------ | ---------------------- |
| `protocol/npm.go`            | `requestBaseURL(c)` 包级 | 方法化，优先 publicURL |
| `api/repository_handlers.go` | `apiBaseURL(c)` 包级     | 方法化，优先 publicURL |

## 5. 验收标准

- 配置 `JIAN_PUBLIC_URL=https://repo.wcpe.top` 后：
  - npm 拉取 packument 的 `dist.tarball` 指向 `https://repo.wcpe.top/npm/...`；
  - 各格式 usage 片段地址为 `https://repo.wcpe.top/...`；
  - 响应中**不出现源站地址**。
- 未配置时：行为与现状一致（Host 推断 + `X-Forwarded-Proto`）。
- 测试：handler 测试覆盖两种配置态；既有测试全绿。
- 实机（FR-88 落地后整体验收）：CDN 回源下经 CDN 域名访问，usage 复制 / npm 拉取 URL 均正确且无源站 IP。

## 6. 风险 / 待定

- `X-Forwarded-Host` 是否可信取决于 CDN 回源配置；public URL 显式配置最可靠（首选）。
- 若 public URL 带路径前缀（少见），本期按"scheme://host"处理，路径前缀后续再评估。
