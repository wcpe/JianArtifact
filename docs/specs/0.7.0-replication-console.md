# 功能规格：集群配置与管理面（web + CLI）

> 状态：已交付@v0.7.0　·　关联 PRD：FR-86　·　分支：main　·　依赖：FR-83/84/85、ADR-0013（复制通道已随 FR-138 退役，本文为历史实现记录）

> 历史规格：当前集群页仅展示静态角色、单一来源和同步状态；级联目标的直接父边/直接子边视图见 0.8.0 FR-119，角色、父子关系、令牌及 peer 不可由运行时管理面修改。

## 1. 背景与目标

FR-83~85 已落地复制引擎（变更日志 / 协议 / 调度）。FR-86 补齐**运维管理面**：让管理员能查看集群同步状态、启停调度——经 CLI 与 web 管理页。对端 URL / 令牌仍为**部署期环境变量**（`JIAN_SYNC_PEER_URL` / `JIAN_SYNC_TOKEN`），**不在运行时编辑**（令牌凭据不入库，符合 SECURITY 约束）。

目标（对用户）：

- CLI：`jianartifact replication status` 查看对端配置 / 同步水位 / 最近同步 / 错误；`start` / `stop` 启停同步调度；
- web 管理端「集群」页：展示同步状态 + 启停开关（仅管理员）；
- 调度器感知启停开关（持久化），web/CLI 的启停即时生效。

## 2. 需求（要什么）

- **持久化开关与状态**（`setting` 表）：
  - `repl:enabled`（`true`/`false`）：同步调度启停；缺省视为 `true`（配置了对端即默认运行）。
  - `repl:last_sync_at`：最近一次成功同步的时间（RFC3339）。
  - `repl:last_error`：最近一次同步失败的错误摘要（成功同步后清空）。
- **调度器改造**（FR-85 的 `ReplicationScheduler`）：
  - 每轮 tick 前读 `repl:enabled`，为 `false` 时跳过同步（保留轮询，开关恢复即继续）；
  - 每次 syncOnce 后写 `repl:last_sync_at`（成功）或 `repl:last_error`（失败）。
- **CLI**（`jianartifact replication <status|start|stop>`）：
  - `status`：显示对端 URL、令牌是否已配置（不显示明文）、调度启停状态、对端水位、最近同步时间、最近错误；
  - `start`：写 `repl:enabled=true`；`stop`：写 `repl:enabled=false`；
  - 对端未配置（无 `JIAN_SYNC_PEER_URL`）时 `status` 提示未配置，`start/stop` 报错。
- **web 管理 API**（非契约，经 `WithProtocolRoutes`，admin 校验）：
  - `GET /api/v1/cluster`：集群状态（node_id、peerURL、tokenConfigured、enabled、watermark、lastSyncAt、lastError）。
  - `PUT /api/v1/cluster`：body `{enabled: bool}`，写 `repl:enabled`。
- **web 集群页**（`/cluster`，仅管理员可见）：
  - 展示上述状态（卡片/列表）；「启用同步」开关调 `PUT`；未配置对端时提示"未配置复制对端"。
  - 侧边栏「管理」段新增「集群」入口；devmock 补充集群状态 mock。
- **不做**：对端 URL / 令牌的运行时编辑（保持环境变量部署）；多对端；复制历史明细页。

## 3. 设计（怎么做）

### 3.1 后端

```
domain.ReplicationScheduler（改造）
  ├─ run 每轮：读 repl:enabled（缺省 true）→ false 跳过
  └─ syncOnce：成功写 repl:last_sync_at，失败写 repl:last_error

cmd CLI（commands.go / replicationCmd）
  ├─ replicationCmd(args)：status / start / stop
  └─ 经 openServices + cfg 读取 / 写入 setting

api（replication_handlers.go 增补）
  ├─ GetClusterStatus：读 setting（enabled/watermark/last_sync_at/last_error）+ cfg（peer/tokenConfigured/node_id）
  └─ PutClusterStatus：admin 校验，写 repl:enabled
main（WithProtocolRoutes）注册 GET/PUT /api/v1/cluster
```

### 3.2 前端

```
pages/ClusterPage.tsx（新）：读 GET /api/v1/cluster → 展示 + Switch 启停
app/router.tsx：/cluster 路由（RequireAuth + 仅 admin 入口）
app/AppLayout.tsx：管理段加「集群」NavLink（adminOnly）
api/endpoints.ts：getClusterStatus / setClusterEnabled
devmock store/msw：集群状态 mock（admin 可见）
i18n：nav.cluster 等文案
```

## 5. 验收标准

- **CLI status**：配置了对端时显示 URL/令牌配置态/水位/最近同步/错误；未配置时明确提示。
- **CLI start/stop**：写 `repl:enabled`；调度器下一轮生效（stop 后不再同步，start 后恢复）。
- **web API**：`GET /api/v1/cluster` 返回状态；`PUT` 仅 admin 可写（非 admin 403）；`enabled` 生效。
- **web 页**：`/cluster` 仅管理员导航可见；显示状态；开关调 `PUT` 后状态即时刷新；未配置对端提示。
- **状态持久化**：调度器成功/失败写 last_sync_at/last_error；重启后 CLI/web 可读。
- **测试**：CLI 子命令测试、集群端点 handler 测试、调度器 enabled 开关测试（stop 跳过 / start 恢复）；既有测试全绿。
- **实机（整体验收，用户确认）**：两台机器组主备后，CLI/web 可查看同步状态并启停；启停生效。

## 6. 风险 / 待定

- **对端配置不运行时编辑**：改对端需重启（改环境变量）；本期接受（令牌不入库的代价）。
- **enabled 语义**：仅控制"是否调度同步"，不停止已运行的 HTTP 服务。
- **web 页 devmock**：集群状态为 admin 端点，devmock 需按登录角色返回（与 licenses 同先例）。
