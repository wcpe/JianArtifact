# 功能规格：设置页统一化

> 状态：已交付@v0.7.0　·　关联 PRD：FR-90　·　分支：main

## 1. 背景与目标

实例级配置目前分散在多个页面：集群页管对端配置（URL/令牌/自动开关）+ 状态 + 同步历史，用户页管匿名访问开关，对外 URL / 回源超时 / 同步间隔（FR-89 已入库 `setting`）**没有 web 配置入口**。

目标：新建独立「设置」页统一管理实例级配置，集群页专注状态与历史查看。后端契约由 FR-89 提供（`GET/PUT /api/v1/settings` 基础四项 + 既有 `GET/PUT /api/v1/cluster` 集群配置）。属 P2，集群期（0.7.0）延展。

## 2. 需求（要什么）

- 侧边栏「管理」新增「设置」入口（仅管理员），路由 `/settings`。
- 设置页一级 tab：
  - **基础设置**：匿名访问开关（Switch）、对外 URL（TextInput）、回源超时（NumberInput 秒）、同步间隔（NumberInput 秒）。读 `getSettings` 展示当前生效值，保存走 `putSettings`（部分字段），成功提示、失败报错。
  - **集群**：对端 URL（TextInput）、对端令牌（PasswordInput，**留空保持不变**）、自动同步开关（Switch）。读 `getClusterStatus` 展示，保存走 `setClusterConfig`（复用 FR-88 端点）。
- **迁移**：
  - 用户页移除匿名访问开关卡片（`AnonymousAccessCard`）。
  - 集群页移除配置表单（对端 URL/令牌/自动开关）；保留「集群（状态）/ 同步历史」双 tab 与「立即同步」按钮（状态相关操作留在状态页）。
- 范围内：仅 web 前端组装 + 文案 + 路由/导航。
- 范围外：不动后端端点（FR-89 已交付）；不引入前端组件测试框架（项目无先例，见 §6）。

## 3. 设计（怎么做）

### 3.1 路由与导航

- `apps/web/src/pages/SettingsPage.tsx`（新）：`export function SettingsPage()`。
- `apps/web/src/app/router.tsx`：`lazy` 引入，`/settings` 路由 `RequireAuth` 包裹（与 `/cluster` 同款）。
- `apps/web/src/app/AppLayout.tsx`：`NAV_SECTIONS` 管理段在「集群」前加 `{ labelKey: "nav.settings", path: "/settings", icon: <IconSettings size={18} />, adminOnly: true }`（`IconSettings` 自 `@tabler/icons-react`）。

### 3.2 SettingsPage 结构

- 页面头 `PageHeader`（title/description 用 `settings.*` 文案）。
- `Tabs defaultValue="basic"`，两个 tab：
  - **基础设置（`basic`）**：`Card` 内 4 项：
    - `Switch` 匿名访问（`settings.anonymousLabel` / `settings.anonymousHint`）
    - `TextInput` 对外 URL（`settings.publicUrlLabel`；placeholder 空；提示"留空则按请求域名推断"）
    - `NumberInput` 回源超时（秒，`min=1 max=3600`）
    - `NumberInput` 同步间隔（秒，`min=1 max=3600`）
    - 保存按钮（loading 态）；点击 `putSettings({...})`，成功 `notifySuccess(t("common.saved"))` 并更新本地值，失败 `notifyError`。
  - **集群（`cluster`）**：`Card` 内 3 项：
    - `TextInput` 对端 URL（placeholder `https://repo1.wcpe.top`）
    - `PasswordInput` 对端令牌（`settings.peerTokenPlaceholder` = 留空保持不变；保存时空串不上送）
    - `Switch` 自动同步（`cluster.enabledLabel` / `cluster.enabledHint`）
    - 保存按钮（loading 态）；点击 `setClusterConfig({ peerUrl?, peerToken?, enabled? })`（令牌空串省略），成功提示 + 令牌输入框清空（不回显），失败报错。
- 状态管理：`useState`（对齐集群页现有风格）；两个 tab 数据独立加载（`useAsync` 或 `useEffect`），互不阻塞。

### 3.3 迁移改动

- `apps/web/src/pages/UsersPage.tsx`：删除 `AnonymousAccessCard` 组件、`AnonymousAccessCard` 在 JSX 中的使用、以及 `getAnonymousAccessSetting` / `putAnonymousAccessSetting` 相关 import（连同不再使用的 `Switch` import 一并清理）。
- `apps/web/src/pages/ClusterPage.tsx`：
  - 删除「对端配置表单」Card（peerUrl/peerToken + 保存）。
  - 删除「同步控制」Card 中的自动同步 `Switch`；保留「立即同步」按钮。
  - 保留状态 Card（nodeId/peerUrl/tokenSet/watermark/lastSync/lastError）与「同步历史」tab 全部逻辑。
  - 「立即同步」按钮移到状态 Card 内（页头右侧或状态 Card 尾部一行）。
  - 清理不再使用的 import（如 `TextInput`、`Switch`、`setClusterConfig` 若不再用则删）。
- 若 `ClusterStatus` 中 `enabled` 字段不再被集群页使用（自动开关迁走），集群页状态展示可保留（`enabled` 仍随 `getClusterStatus` 返回）。

## 5. 验收标准

- 侧边栏「管理」出现「设置」（仅管理员；非 admin 不显示）。
- `/settings` 页：基础设置 / 集群 两个 tab 可切换，各自独立加载不阻塞。
- 基础设置：展示当前生效值；修改对外 URL / 回源超时 / 同步间隔 / 匿名开关保存成功并提示；刷新页面值保持（后端已持久化）。
- 集群 tab：展示对端 URL / 令牌配置态 / 自动开关；保存对端 URL + 令牌成功；令牌输入框保存后清空（不回显）；令牌留空保存不变更。
- 用户页无匿名开关卡片；集群页无对端配置表单与自动同步开关，保留状态、立即同步按钮与同步历史。
- 前端 `typecheck` / `lint` / `build` / `test` 全绿。
- 实机（真机，需用户确认）：浏览器设置页保存后，不重启即生效——改同步间隔后集群日志显示间隔调整；改对外 URL 后 usage 片段用新域名。

## 6. 风险 / 待定

- 前端组件测试：项目目前无组件测试框架（仅纯函数单测）。本 FR 不引入 `@testing-library` 新依赖；质量门以 typecheck/lint/build + 实机验收为准。若后续需要组件测试，另开任务并确认依赖。
- 「立即同步」按钮保留在集群页（状态相关操作）；设置页集群 tab 只做配置，不重复放操作按钮。
