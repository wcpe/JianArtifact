# 功能规格：仓库列表上游探测状态展示

> 状态：草拟　·　关联 PRD：FR-114　·　分支：feature/repository-connection-status-ui

## 1. 背景与目标

FR-112 的 auto-block 状态机产生仓库级连接状态，FR-113 引入 online/offline。需要把这些状态暴露给管理员：**仓库列表展示上游连接状态徽章**（可用/自动阻止/离线/错误），仓库详情页提供 **online/offline 开关 + 手动重测按钮**，让运维直观看到"上游仓库什么情况"并主动干预。

## 2. 需求（要什么）

- **仓库列表状态列**：proxy 仓库列表新增"连接状态"徽章：
  - `AVAILABLE`（可用，绿）
  - `AUTO_BLOCKED`（自动阻止，橙/红）——含 blockedUntil
  - `UNAVAILABLE`（不可用，红）
  - `OFFLINE`（离线，灰）
  - `READY`/`UNINITIALISED`（未连接，灰）
- **状态合并展示规则（MD-2）**：FR-112 的连接状态为内存态，FR-113 的 online 为持久化态，二者需合并展示，规则如下：
  - **online=false（离线，灰）优先覆盖**其它状态：仓库 offline 时，无论内存态是 AUTO_BLOCKED/UNAVAILABLE/AVAILABLE，一律显示「离线(灰)」。
  - offline 仓库**不参与 auto-block 探测/展示**：offline 时不发后台 HEAD 探测，也不更新 auto-block 状态（或冻结当前状态）。
  - 仅 online=true 时显示内存态连接状态（AVAILABLE/AUTO_BLOCKED/UNAVAILABLE/READY）。
  - 手动 BLOCKED（若实现）与 offline 独立：BLOCKED 显示「手动阻止(红)」。
- **详情页 online/offline 开关**：proxy/group 仓库详情可切 online/offline（FR-113），offline 时状态显示"离线"。
- **手动重测按钮**：详情页/列表行提供"重新探测"按钮，触发一次上游 HEAD 探测刷新状态（立即检查上游是否可用，不等到 auto-block 窗口）；仅 online 仓库可重测。
- **状态可查**：连接状态经管理 API 返回（`GET /api/v1/repositories` 列表或详情含 connectionStatus）。
- **范围内**：proxy/group 仓库状态展示与手动干预；admin 可见。
- **不做（范围外）**：自动告警、历史状态趋势、跨节点状态聚合。

## 3. 设计（怎么做）

- **契约**（`api/openapi.yaml` + `task gen` + devmock gen）：
  - `Repository` 响应模型加 `connectionStatus`（枚举 + blockedUntil + 说明）。
  - `PUT /api/v1/repositories/{name}/online`（body `{online:bool}`，仅 admin）——FR-113。
  - `POST /api/v1/repositories/{name}/recheck-connection`（仅 admin）——手动重测。
- **后端**：
  - `AssetService`/`proxyHealth`（FR-112）暴露 `Status(repoID)` 查询。
  - `RepositoryService.ListWithStats`/`Get` 填充 `connectionStatus`。
  - 手动重测端点：触发 `proxyHealth` 立即 HEAD 探测并返回新状态。
  - `SetOnline`（FR-113）联动状态展示。
- **前端**：
  - `RepositoriesPage`：proxy 仓库行加连接状态徽章（Badge 按状态着色）。
  - `RepositoryDetailPage`：online/offline 开关 + 重新探测按钮 + 状态显示。
  - `endpoints.ts`/`types.ts`：类型 + API。
  - `i18n/zh.ts`：状态文案。
- **devmock**：mock 状态 + 路由 + 契约测试。

## 5. 验收标准

- proxy 仓库列表显示连接状态徽章（可用/自动阻止/离线/错误），颜色区分正确。
- 详情页 online/offline 开关生效（FR-113），切换后状态显示更新。
- 手动重测按钮触发上游探测，状态刷新（上游不可达 → 自动阻止；恢复 → 可用）。
- 状态经管理 API 返回，admin 可见，非 admin 401/403。
- 前端 typecheck/lint/test、后端 go test/race/vet、devmock 契约全绿。

## 6. 风险 / 待定

- 状态为内存态（FR-112），重启重置为 READY——列表状态在重启后回到初始，可接受。
- `connectionStatus` 加入 Repository 契约是向后兼容（新增可选字段）。
- 手动重测频率需限流（防刷），可加最小间隔。
