# 功能规格：管理控制台信息架构与账户菜单

> 状态：已交付@v0.8.0　·　关联 PRD：FR-117、FR-118　·　目标版本：v0.8.0

## 1. 背景与目标

当前顶栏将身份文字与退出按钮分开排列，窄桌面会拥挤重叠；侧栏把运维、账户和许可证混在同一段；设置页又把不可编辑的集群部署变量当作设置展示。

本功能将管理台收敛为稳定、可理解的信息架构，不改变既有权限判定和业务路由语义。

## 2. 需求

- 顶栏以一个可访问的账户菜单展示用户名、角色与退出登录；不再并列展示独立身份文字和退出按钮。触发器为紧凑身份胶囊：首字母头像、用户名、角色与展开指示；菜单首段为非交互的当前会话身份信息，下面只保留一个退出登录动作。
- 页眉在刷新按钮与账户菜单之间提供仅全局管理员可见的风险通知中心。它固定显示当前节点最近 24 小时未确认的失败或高风险审计批次；响应返回未确认总数和按失败优先、同级最新排序的至多 20 条预览。数字与文字无障碍名称同时表达未确认总数，不能只依赖红点；超过预览上限时展示「查看全部审计」入口。通知项只展示结果、操作、对象、脱敏摘要与时间；点击携带权威 `attentionId` 跳转审计页对应批次详情，并可由该详情发起确认。读取失败明确显示不可用，不能伪装为零风险。通知中心不轮询、不使用 WebSocket，在挂载、现有全局刷新和确认成功后刷新。
- 侧栏严格按「概览」（仪表盘、仓库）、「运维」（集群、审计日志、主机监控）和「管理」（用户、访问令牌、迁移、设置）三个区段及该顺序展示；每个入口只能归属一个区段。开源协议固定在侧栏底部、收起导航按钮上方，不属于上述区段。
- 设置页只保留可由管理员保存且运行时生效的「服务设置」，不再保留没有第二个内容区的标签页。集群标签及其环境变量名、同步令牌状态和部署说明全部移出设置页。
- 集群页承担只读拓扑和同步诊断；不得恢复运行时角色、来源或令牌编辑。
- 管理员与普通用户的菜单可见性必须继续由后端权限结果和既有前端可见性规则控制，布局重构不得扩大权限。

范围内：桌面、窄桌面和移动端布局；中文文案与键盘可用性；风险通知中心与审计确认状态的展示。

不做：新增权限模型、运行时集群配置、跨节点通知汇总、浏览器本地忽略状态、轮询/推送通道、许可证内容修改或新的 UI 组件依赖。

## 3. 设计

复用 Mantine 的 Menu、Avatar、侧栏分组、现有 PageHeader 和路由守卫。账户菜单触发器必须有完整无障碍名称，菜单关闭后焦点回到触发器；身份信息用普通内容展示，不能伪装成 disabled 菜单操作。通知触发器同样支持 Enter/Space 打开、Esc 关闭并返回焦点；通知项是链接而不是承载完整详情的菜单。链接仅传递服务端签发的 `attentionId`，审计页据此加载批次详情；客户端不得从摘要拼接成员或以本地时间桶作为确认边界。设置页删除只读集群表单，集群页面保留现有 standby 专属受控同步能力。风险确认的权威规则、审计与接口见 `0.8.0-audit-observability.md`，本页只消费其只读通知摘要。

## 5. 验收标准

- 876px、1316px 和移动宽度下，搜索、账户菜单和导航互不重叠、不溢出。
- 鼠标与键盘均可打开账户菜单，Enter/Space 可触发、Esc 可关闭且焦点正确返回；退出登录仍可用。
- 管理员看到「概览」内的仪表盘、仓库，「运维」内的集群、审计日志、主机监控，「管理」内的用户、访问令牌、迁移、设置；入口不会出现在其他区段，底部许可证不混入区段。普通用户不会因此看到未授权入口。
- 未登录的公开仓库导航不回归；收起导航后许可证入口仍有可理解的 tooltip 和无障碍名称。
- 通知中心只向全局管理员显示最近 24 小时未确认项；正常、空态、加载与失败均有明确可访问反馈。响应含未确认总数、至多 20 条失败优先的预览和超限时的「查看全部审计」入口。确认后数量与审计关注队列同步更新，点击通知能用 `attentionId` 进入对应本节点批次详情并从该处确认，且不泄露诊断敏感字段。
- 设置页不再出现集群标签、环境变量名、同步令牌或不可编辑部署字段；单一服务设置内容区不再以标签页包裹。
- 所有受影响页面的单元测试、前端类型检查、lint 与构建通过；浏览器覆盖上述三个宽度的真实交互。

## 6. 风险 / 待定与验收边界

- 不引入新的图表或菜单依赖；仅使用现有 Mantine 与图标包。
- `make check` 已通过；本地开发服务器的 DevMock 浏览器验证已核对导航、账户菜单和通知中心的正常、空态、加载、失败与跳转行为。该验证仅证明本地开发态 UI，不构成线上验收或用户验收。
- 用户验收仍以第 5 节为准，需在实际会话中覆盖三个页面宽度的账户菜单、导航与通知中心交互。
