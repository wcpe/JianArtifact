# 功能规格：管理员直接填写 Nexus 迁移地址

> 状态：开发完成，待用户验收　· 关联 PRD：FR-116 · 分支：当前工作区

## 1. 背景与目标

管理员迁移外部 Nexus 时，现有 online REST 流程要求部署者先配置 `JIAN_MIGRATION_SOURCE_<名称>`，管理端只能填写该名称。对一次性的外部 Nexus 迁移，这增加了不必要的部署步骤。

目标是让管理员直接填写 Nexus REST 基址并创建可恢复的在线迁移任务。

## 2. 需求（要什么）

- 管理员在 online REST 迁移向导直接填写 Nexus 基址，例如 `https://bak.maven.wcpe.top`。
- 管理员可选择匿名、Basic（用户名/密码；Nexus User Token 的名称/Passcode 同属此项）或 Bearer Token（JWT、Access Token、npm Token）认证。
- 任务持久化已校验的基址和加密后的认证材料，以支持发现、启动、恢复和最终增量；不再要求 `sourceRef`。
- 保留 `sourceRef` 作为已有任务的兼容输入；新建任务可二选一，不能同时提供。
- 仅允许无用户信息、无查询参数和无片段的绝对 `http` / `https` 地址。
- 继续使用现有统一出站客户端；私网、环回、云元数据、危险重定向和跨 origin 下载地址仍被拒绝。
- 凭据由本次请求的 `sourceAuth` 提交，标为仅写入；密码、Passcode 与 Token 不出现在响应、任务详情、草稿、报告、审计或日志中，也不写入 URL。

范围外：来源白名单、来源配置管理、交互式 SSO/Cookie 登录、客户端证书认证、非 Nexus 来源和协议迁移行为调整。

## 3. 设计（怎么做）

- 以 ADR-0025 取代 ADR-0022 对 online REST 迁移来源仅限 `sourceRef` 的限制。
- `MigrationSourceConfig` 恢复既有的 `url` 字段；持久化配置允许 `sourceRef` 或 `url` 二选一。
- 新请求使用 `sourceAuth` 联合体：`anonymous`、`basic{username,password}` 或 `bearer{token}`；Basic 同时覆盖 Nexus User Token 的名称/Passcode。旧任务的 `credentialRef` 保持兼容。
- `migration_task` 增加明文的认证类型与 AES-256-GCM 密文列；密文以独立的迁移凭据密钥加密，密钥由 `JIAN_MIGRATION_CREDENTIAL_KEY` 提供，未配置时在数据目录创建仅服务账户可读的密钥文件。密钥和密文均不通过 API 返回。
- 发现、任务执行、resume、finalize 与远程仓库索引统一解析两种来源和认证方式，直接 URL 仍先经现有 URL 语法校验和统一出站校验。认证头仅发送给同 origin 的 Nexus 地址。
- 管理端在线迁移向导改为“来源 URL”输入框与认证方式选择；远程仓库索引 API 接受同一来源语义。密码和 Token 仅保存在当前表单内存，切换方式、创建完成或离开页面即清除，绝不写入 sessionStorage 草稿。
- 来源 URL 可由管理员任务详情返回；认证类型可显示，但用户名、密码、Passcode、Token、密文与密钥不得写入迁移报告、失败摘要、应用日志或审计 detail。

## 4. 任务拆分

- [x] OpenAPI、Go 领域来源解析与任务持久化支持 `url` / `sourceRef` 二选一，以及仅写入的 `sourceAuth`。
- [x] 迁移凭据密钥、AES-256-GCM 加密存储与旧 `credentialRef` 兼容。
- [x] 在线发现、执行、恢复、finalize 与远程索引复用直接 URL 和认证解析。
- [x] 管理端迁移向导支持 URL、匿名/Basic/Bearer 认证；不把秘密写入草稿或详情。
- [x] 覆盖直接 URL、三种认证、非法 URL、私网拒绝、密文不回显、任务恢复和历史 sourceRef 兼容测试。
- [x] 文档同步：PRD、ARCHITECTURE、API、ADR、CHANGELOG、OPERATIONS。

## 5. 验收标准

- 管理员可仅填写 `https://bak.maven.wcpe.top`，或附加 Basic／Bearer 认证，发现并创建 planned 迁移任务，选择 `maven-releases` 后显式启动。
- 任务恢复和最终增量使用同一持久化 URL 和加密凭据，不依赖服务器环境变量。
- URL 中的用户信息、查询参数、片段、非 HTTP(S) 协议及私网解析均被拒绝；拒绝信息不包含敏感凭据。
- Basic、Nexus User Token pair 与 Bearer Token 均可访问相应的私有 Nexus；认证头不会被重定向或跨 origin 下载带走。
- 密码、Passcode、Token、密文和密钥在 HTTP 响应、SQLite 查询结果的管理 API、sessionStorage、迁移报告、审计和日志中均不可见。
- 历史 `sourceRef` 任务仍可发现、启动、恢复和最终增量。
- 相关 Go、前端契约和管理端实机迁移验证通过；真实备份源补传后，备份缺失路径为零。

## 6. 风险 / 待定

- 直接 URL 会出现在管理员任务的持久化来源配置中；认证类型可见但认证材料只有密文；该变化由 ADR-0025 明确接受。
- 108 当前部署尚未包含本功能，需在实现、验证和部署后才能使用直接 URL 补传。
