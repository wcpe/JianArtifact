# 功能规格：当前主机监控

> 状态：开发中　·　关联 PRD：FR-120　·　目标版本：v0.8.0

## 1. 背景与目标

业务仪表盘不能说明当前服务是否受到 CPU、内存、磁盘、网络或进程资源限制。管理员需要在本实例看到连续的主机性能趋势，但不需要也不允许跨节点采集或汇总。

本功能提供仅属于当前实例所在主机的性能页面；一分钟一个样本，最多保留三十天。

## 2. 需求

- 在「运维」导航新增“主机监控”入口，仅管理员可访问。
- 每分钟采集当前主机 CPU、主机内存、数据目录所在文件系统的可用磁盘、非回环网络接口汇总收发速率、JianArtifact 进程 RSS/CPU、goroutine，以及 `/readyz` 健康状态。Linux 可额外显示打开文件描述符数；其他平台必须标记为不支持，不以“句柄可用”伪造跨平台值。
- 数据持久化于本节点 SQLite，每个 UTC 分钟仅一条样本。主机、数据卷、网络、进程和就绪五个指标组分别有 `ok`、`unavailable`、`unsupported` 或 `error` 状态及稳定脱敏错误码，数值可为 `null`；保留 30 天。清理任务仅定时执行，不得在服务启动时扫描，不得影响制品、审计、同步状态或其他节点数据。
- 页面提供当前值、24 小时/7 天/30 天趋势和最近采样时间。API 在最近样本超过两个采样周期时返回 `stale`，首次尚未采样返回 `unknown`；采集失败、平台不支持或样本过期必须明确显示，禁止显示伪造的 0。
- 只监控当前实例所在主机，不读取其他节点、不发起远程请求、不使用复制凭据、不把指标参与复制。

范围内：本地采样、保留清理、管理员读 API、可访问趋势展示。

不做：跨节点监控、外部指标库、Prometheus 替代、告警通知渠道、进程参数/环境变量/文件路径采集。

## 3. 设计

本功能自带最小的分钟采样调度，不依赖尚未交付的 FR-44；后续 FR-44 如引入统一调度器，只能以等价行为替换该内部触发方式。平台适配器读取实际主机和当前进程统计。样本以 `UNIQUE(bucket_start)` 保存，CPU 与网络速率均由相邻成功样本的计数差和实际采样间隔计算；首个成功样本的速率为 `unavailable`/`null`，不能填 0。内存使用明确返回 total/available，磁盘只针对数据目录所在文件系统。失败也持久化为指标组状态样本，避免时间线无故断裂。按时间范围聚合后返回；前端使用现有组件或轻量 SVG，并有文本/表格替代。新增 API 必须进入 OpenAPI、生成代码与 devmock，不扩展任何未契约的管理端点。

| 接口                             | 权限       | 关键参数                                    | 返回                                                                                                                |
| -------------------------------- | ---------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `GET /api/v1/observability/host` | 全局管理员 | `from`、`to`（UTC `[from,to)`，最大 30 天） | 当前实例标识、`hostState`（`healthy`/`stale`/`unknown`）、最新样本、各指标组状态、`effectiveBucket`、趋势与采样时间 |

服务端固定趋势粒度：范围不超过 24 小时返回分钟桶，超过 24 小时且不超过 7 天返回小时桶，超过 7 天返回天桶；前端按 `effectiveBucket` 渲染。

## 5. 验收标准

- 受控时钟下每个 UTC 分钟至多产生一条当前节点样本，重启后继续采样；超过 30 天的数据仅由定时任务清理，边界样本保留正确，启动不触发全库扫描。
- CPU、内存、数据目录磁盘、非回环网络汇总和进程数据与可复核的本机来源一致；每个指标组无法读取、平台不支持或采样失败时返回明确持久状态与脱敏错误码而非 0，其他指标组仍可正常展示。
- 管理员可查看 24 小时、7 天、30 天趋势；服务端拒绝非法/超过 30 天的范围；非管理员无法读取 API 或页面。
- 采样器停机后的最近样本在超过两个采样周期时为 `stale`，首次采样前为 `unknown`；历史样本不被误渲染为当前健康。
- 页面和响应不含其他节点、进程参数、环境变量、令牌、文件路径或制品内容。
- 采样/清理/API/权限测试、前端无障碍测试、契约/devmock 校验、类型检查、lint 与构建通过；真实运行实例连续观察至少两个采样周期并核对当前值。
