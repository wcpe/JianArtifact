# 功能规格：hosted 格式感知删除

> 状态：已交付@v0.8.0　·　关联 PRD：FR-105（原 FR-106 并入）　·　分支：main　·　依赖：FR-104、FR-105

## 1. 背景与目标

Raw 路径是普通文件层级，但 Maven 与 npm 的路径承载协议元数据。管理端删除必须按逻辑制品边界执行，不能留下失效 metadata 或 packument。

## 2. 需求

- Raw hosted：允许删除任意文件或目录子树。
- Maven hosted：仅允许删除 `group/path/artifact/version/` 完整版本根或 `group/path/artifact/` 完整 artifact 根；服务端重建受影响 `maven-metadata.xml` 与校验和。直接选择 POM、校验文件或 metadata 返回 `409 logical_delete_required`。
- npm hosted：仅允许按包名或 `package@version` 逻辑目标删除完整包或完整版本；统一 API 用 typed target 表达 `npm_package`、`npm_version` 或来自文件树的 `asset_path`，后端把 tarball/packument 的 `asset_path` 唯一映射为所属逻辑目标。未带类型的裸路径不得绕过 packument 与关联 tarball 更新。
- proxy/group 一律拒绝；所有删除仅全局管理员。
- 不做：Maven/npm 的管理端移动、路径修改或重命名。

## 3. 设计

格式规划器将 typed target 转换为完整资产计划和派生 metadata 更新，再交 FR-104 原子引擎执行。Maven 的版本根和 artifact 根、npm 的包名和 `package@version` 是唯一可删除逻辑根；文件树传入的 npm `asset_path` 必须先解析为唯一逻辑根，直接协议 DELETE 或不带类型的裸路径返回 `409 logical_delete_required`，而非猜测性递归删除。

## 4. 任务拆分

- [ ] 实现 Raw、Maven、npm 的删除规划与格式校验。
- [ ] 实现 Maven metadata/校验和重建及 npm packument 更新。
- [ ] 接入协议删除、npm unpublish 与统一管理操作入口。
- [ ] 文档同步：PRD、ARCHITECTURE、API、CHANGELOG。

## 5. 验收标准

- Maven 删除版本或 artifact 后，原生 Maven 客户端读取 metadata 与下载行为正确。
- npm 删除版本或包后，packument 与 `npm install` 一致。
- Maven POM、校验文件、metadata 与 npm 不带类型的 tarball/packument 裸路径删除均返回 `409 logical_delete_required`；文件树发送 typed `asset_path` 时可映射为唯一 npm 逻辑目标。非法粒度、非管理员、proxy/group 操作均拒绝且不留元数据或 blob 半状态。

## 6. 风险

格式派生资产计入 500 条操作上限，超限必须在写入前拒绝。
