# 功能规格：业务仪表盘、容量趋势与站内运维告警

> 状态：已交付@v0.8.0　·　关联 PRD：FR-53　·　目标版本：v0.8.0

## 1. 背景与目标

现有仪表盘只显示版本、就绪和迁移版本等实例信息，无法回答仓库有多少内容、容量如何变化、请求是否异常。主机资源属于不同关注面，必须单列到 FR-120。

本功能提供基于服务真实业务数据的运营概览，不把主机 CPU、内存或磁盘数据混入该页面。

## 2. 需求

- 默认展示近 24 小时业务概览，并提供 7 天、30 天范围切换。
- KPI 至少包括仓库数、制品数、逻辑制品体积、请求量、下载量、失败请求量和缓存命中率；值必须来自后端聚合，禁止前端猜测或占位。逻辑制品体积以当前 asset 记录大小之和计算，不把内容寻址 blob 的物理去重体积混入该值。
- 展示请求/下载/失败趋势与容量增长趋势；图表应同时提供可读的文本摘要或表格替代。
- 站内运维告警仅展示已经有确定后端状态依据的异常：实例未就绪、当前节点同步失败或上游自动阻止；每项固定返回 `code`、`severity`、`source` 和 `observedAt`。不新增外部通知渠道、结构化存储故障原因或没有配置来源的容量阈值。
- 业务请求按分钟聚合并至少保留 30 天；容量快照每小时记录一次并至少保留 30 天；两类清理都只由定时任务执行，不得在启动时扫描或清理。不得为每次下载额外写入完整审计日志。
- 统计口径固定：请求为已完成的制品协议请求，排除健康、管理和静态页面；下载为成功返回 `200` 或 `206` 的制品 GET；失败请求为制品协议最终 `5xx`，不把预期 `404`、认证或 ACL 拒绝计入；缓存命中率仅计算可缓存的 proxy/group 读取，分母为有明确命中或未命中结果的读取，hosted/raw 读取和未知缓存结果不计入。

范围内：业务指标采集、聚合 API、仪表盘可视化和站内异常状态。

不做：主机性能图、外部监控平台、短信/邮件/Webhook 告警和新的第三方图表库。

## 3. 设计

在 HTTP 入口以低开销计数器记录请求、下载和最终服务错误；protocol/domain 只通过受限 request context 写入明确的缓存命中结果，避免 middleware 猜测缓存状态。后台按分钟落入请求聚合表、按小时落入容量快照表；仓库、资产和逻辑体积从真源 SQLite 查询。API 返回时间范围、当前快照和按分钟/小时桶聚合，前端使用现有组件或轻量 SVG 呈现。API 契约以 `api/openapi.yaml` 为真源，devmock 与生成代码必须同步。

| 接口                                  | 权限       | 关键参数                                    | 返回                                                                     |
| ------------------------------------- | ---------- | ------------------------------------------- | ------------------------------------------------------------------------ |
| `GET /api/v1/observability/dashboard` | 全局管理员 | `from`、`to`（UTC `[from,to)`，最大 30 天） | 当前快照、请求聚合、容量快照、缓存口径、`effectiveBucket` 与站内异常状态 |

服务端固定趋势粒度：范围不超过 24 小时返回分钟桶，超过 24 小时且不超过 7 天返回小时桶，超过 7 天返回天桶；前端按 `effectiveBucket` 渲染，不能请求分钟级 30 天数据。告警来源固定为 `/readyz`（`instance_not_ready`）、当前节点同步日志和仓库连接状态；没有来源时不返回该告警。

## 5. 验收标准

- 受控请求、下载、失败和缓存命中夹具的聚合值、时间桶、统计口径和范围边界均准确；容量快照能复现给定时间点的逻辑制品体积，重启后不丢失已落库数据。
- 默认近 24 小时及 7 天、30 天视图与后端范围和有效粒度一致；非法时间范围被拒绝，无数据、加载失败和部分指标不可用均有明确状态。
- 仪表盘不显示 CPU、内存、主机磁盘或跨节点数据。
- 图表有非颜色唯一的图例、文本摘要或表格替代，键盘和屏幕阅读器可读取关键趋势与异常。
- API 契约、devmock、后端聚合测试、前端页面测试、类型检查、lint 与构建通过；真实运行实例的指标与可复核请求样本一致。

## 6. 风险 / 待定

- 统计口径不得在前端重复实现；聚合表和容量快照的保留任务依赖 FR-44。
