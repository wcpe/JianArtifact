# 功能规格：级联树逐跳拉取凭据

> 状态：开发完成，待用户验收　·　关联 PRD：FR-121、FR-115　·　目标版本：v0.8.0（尚未发布）　·　决策：ADR-0026

## 1. 背景与目标

主备单向复制已扩展为级联树：根 primary 与 relay standby 都可能向直接下级提供复制源。共享令牌或只允许 primary 创建凭据，无法表达相邻父子边的最小权限，也无法独立撤销某一分支。

本功能把凭据模型固定为逐跳配对：每个父节点只授权自己的直接子节点，每个子节点只持有直接父节点的密封凭据。

## 2. 需求

- 根 primary 和启用中继能力的 standby 都可以为直接下级创建节点专属复制凭据；父节点不需要知道孙节点。
- 凭据绑定父 node ID、子 node ID、父节点基址和 stream generation；更换父节点、人工提升或流代次变化后必须重新配对。
- 父节点只保存不可逆摘要、凭据标识、边绑定信息、创建/撤销/轮换状态和安全审计；不保存可恢复明文。
- 子节点通过本地 CLI 从标准输入导入一次性令牌，并以本数据目录独立的 AES-256-GCM 密钥密封保存。
- 凭据仅允许直接父节点的 capabilities、v2 pull 和 blob 三类 GET；不得访问管理 API、协议端点、业务写入、非白名单 GET 或任何非 GET 方法。
- 令牌不得进入命令行参数、环境变量、Web/API、日志、审计详情、复制载荷、截图或备份明文。
- 轮换必须先创建替换凭据、由子节点导入并验证成功，再撤销旧凭据；撤销后对应父子边停止拉取且不推进 watermark。
- 不做 Web 配对、跨节点配置 POST、全树共享令牌或运行时管理页面编辑拓扑。

## 3. 设计

### 3.1 逐跳配对

```text
父节点 A --创建 child-B 凭据--> B
父节点 B --创建 child-C 凭据--> C
```

A 只保存 B 的凭据摘要，B 只保存 C 的凭据摘要；B 使用 A 的凭据拉取 A，同时使用另一套凭据为 C 提供复制源，两个方向的秘密不能复用。

### 3.2 本地密封与校验

父节点使用随机盐和摘要验证 Bearer 令牌，并校验凭据标识、直接子 node ID、父节点角色/中继能力和请求方法/路径白名单。子节点导入时校验本节点 ID、直接父节点基址和 stream generation；不匹配时拒绝导入或启动该边调度。

节点本地 `replication-credential.key` 独立于 JWT 和迁移凭据密钥，按服务账户权限保存。复制凭据只表示复制读取能力，不改变 standby 的业务只读栅栏。

### 3.3 配对状态

集群监控只显示“未配对、已验证、已撤销、过期/代次不匹配、认证失败”等直接边状态，不显示令牌、摘要、内部地址或完整拓扑。父节点重启不要求重新交付明文；子节点重启从本地密文恢复。

## 4. 任务拆分

- [x] 将凭据摘要从 root-only 扩展为 source/parent-child edge，并为旧空来源字段保留兼容读取。
- [x] 允许启用中继能力的 standby 管理直接下级凭据，不开放业务写入口。
- [x] 将绑定校验扩展到父 node ID、子 node ID 和父基址；stream generation 由能力协商与 relay record 校验保护。
- [x] 保持严格 GET 白名单，补充跨边复用、撤销、轮换和重配对测试。
- [x] 同步集群页面、集群监控、API/脱敏文档与运维配对流程。

## 5. 验收标准

- 根 primary 可为直接 relay/leaf standby 创建凭据；relay standby 可为两个直接下级创建不同凭据；孙节点凭据不出现在根节点。
- B 使用 A 的凭据拉取成功，同时 C/D 只能使用 B 分别授予的凭据拉取 B；任一凭据不能访问另一个父节点或管理/业务接口。
- 新凭据经子节点 `verify` 成功后才能撤销旧凭据；撤销旧凭据只影响对应边，其他边继续同步。
- 父/子 node ID、父基址或已协商 stream generation 不匹配时能力协商和拉取被拒绝，watermark 不推进；旧凭据的 stream 字段为空时仅保留开发兼容路径。
- 令牌明文、密文、密钥和 Authorization 头不出现在数据库可读字段、环境、参数、日志、审计、报告或页面。
- 后端单测、集成/竞态测试、四进程逐跳配对和前端 Mock 已通过；真实凭据轮换/失效后的重启复验仍待用户环境验收，凭据失败时页面显示直接边降级而不伪造全树状态。

## 6. 风险 / 待定

- 中继凭据摘要和子边状态增加每个 relay 节点的本地存储；删除子边前必须明确处理其未确认 relay 数据。
- stream generation 变化会使旧凭据失效，人工提升/重新挂接必须在运维流程中先配对再开放流量。
