# 功能规格：发布账号防护与审计身份增强

> 状态：已交付@v0.8.0　·　关联 PRD：FR-109　·　分支：main　·　决策：ADR-0015

## 1. 背景与目标

CI 可继续使用账号密码发布，但泄露后的凭据不能删除、覆盖既有 Release 或跨仓库投放内容；审计需要能够稳定识别用户与认证来源而不记录任何明文凭据。

## 2. 需求

- 不新增账号类型。普通用户可按用户设置禁止或允许登录 Web/管理 API；默认保持现有允许行为。
- 发布策略按“用户 × hosted 仓库”可选配置。启用后仅允许原生协议发布，拒绝管理写操作；HTTP Basic 用户名口令与既有 API Token 均复用统一策略，Cargo 使用其原生 registry token 通道作为兼容性例外。
- Release 不可变是仓库级策略，不依赖发布策略是否启用。任何既有逻辑发布对象均不得被普通账号覆盖；删除、移动和重命名仅全局管理员可执行。不可变 Release 的管理员特权仅存在于统一管理操作 API，须显式携带非空 `overrideReason` 并审计；原生协议、迁移和复制不得覆盖既有逻辑对象。Maven/npm 服务端派生 metadata 写入不视为绕过。
- 允许配置多个路径前缀；未配置前缀时覆盖该用户获授权仓库的全部路径。
- 支持可选额度：每小时新增制品数、每日上传总字节、单文件最大字节。未配置时沿用仓库默认；额度按用户×仓库×时间窗在 SQLite 中持久化原子 reservation，`used + reserved` 是唯一判定依据。
- 审计增加稳定用户 ID、用户名快照、认证方式、Token ID/名称（如适用）、来源 IP、User-Agent、请求 ID、来源节点与结果；不记录密码、Token 明文或摘要。
- 拒绝发布、额度超限、越权删除和管理员不可变覆盖同样进入审计。暂不加入 IP 白名单。

## 3. 设计

发布策略作为普通用户和仓库 ACL 之上的附加限制，不改变既有 admin/user 身份模型；仓库级不可变策略优先于发布策略且不能被其放宽。协议认证在取得用户身份后执行策略判断，携带 Basic/Bearer/API Token 的协议请求只允许实际 HTTPS、实际 TCP loopback，或 Host 命中节点本地白名单的 CDN HTTP 回源兼容链路；loopback 只依据服务端看到的实际连接对端地址判定，不信任 Host 或转发头。Host 白名单不是来源认证，生产兼容链路还必须叠加 FR-130 回源 Token 或改用 FR-131 HTTPS 回源。`web_login_disabled` 在每次 Web/管理 API 鉴权检查，因此既有 Web JWT、既有 API Token 与浏览器会话立即失效于管理面，不影响原生协议策略。审计身份在认证上下文中构建并传入所有写入 handler。私有上游凭据只保存 ADR-0022 的逻辑 `credentialRef`，运行时只读取 `JIAN_UPSTREAM_CREDENTIAL_<credentialRef>`；所有持久化与诊断输出均不得泄露值、任意环境变量名或解析结果。

额度在上传开始前为“新增制品数”和已知 `Content-Length` 原子预留；未知长度上传按流式接收字节扩展 reservation，在越过单文件或时间窗上限前中止且不提交 asset。Cargo、PyPI、NuGet 与 OCI 分块上传即使尚未解析最终制品路径，也必须先建立可结算预留再写临时文件；路径解析后再补做前缀与不可变 Release 校验。成功提交将 reservation 结算为 used；协议失败、事务失败、断连、OCI 会话超时和启动恢复均释放未结算 reservation。所有配额读写保持短事务，不能依赖进程内计数或在上传结束后才扣减。

## 4. 任务拆分

- [x] 新增发布策略、Web 登录开关、额度 reservation/恢复与迁移。
- [x] 收敛 HTTPS 协议、Web/API、迁移和复制的发布、覆盖和删除权限判断，补 npm unpublish 管理员保护与管理 API `overrideReason` 契约。
- [x] 扩展审计数据模型、查询筛选、OpenAPI/devmock 与管理页展示。
- [x] 文档同步：PRD、ARCHITECTURE、API、CHANGELOG。

## 5. 验收标准

- 启用发布策略的账号能用 HTTPS Basic 账号密码向允许前缀发布新制品，但不能覆盖、删除、跨仓库或越过前缀发布；Cargo 按原生 token 通道验证同一策略。非 TLS、实际 TCP 对端非回环且 Host 未命中显式白名单的携凭据协议请求被拒绝；外部对端伪造 `Host: 127.0.0.1` 不能冒充回环，显式白名单兼容链路须叠加回源 Token 或 HTTPS 回源。
- 不可变 Release 仓库中的既有逻辑对象对所有普通账号、原生协议、迁移和复制拒绝覆盖；管理员仅能通过统一管理 API 携带原因 override，且审计记录原因、操作者和结果。
- Web 禁用账号无法登录 Web 或调用管理 API；开关变更后既有 JWT、API Token 与浏览器会话立即失效于管理面，普通未启用策略账号保持现有行为。
- 多前缀、三种额度和超限拒绝均有测试；并行上传的 `used + reserved` 不能超过上限，未知长度流在超限前中止，失败/断连/重启释放 reservation，额度不在服务重启后丢失。
- 审计页可按用户、认证方式、Token、仓库、结果、IP 筛选，并能区分成功与拒绝；任何记录均不含明文凭据。
- 原生 Maven/npm/Raw 发布与双节点复制实机验收通过。

## 6. 风险

无到期的账号密码泄露后仍需人工改密或禁用账号；本功能通过最小权限、不可变发布、前缀和额度降低影响面，不能消除已授权的新路径发布能力。
