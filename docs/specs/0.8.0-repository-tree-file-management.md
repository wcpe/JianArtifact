# 功能规格：仓库树文件管理交互

> 状态：开发中　·　关联 PRD：FR-105（原 FR-108 并入）　·　分支：main　·　依赖：FR-105

## 1. 背景与目标

复选框批删占用文件树空间且无法表达目录操作。管理员需要接近文件管理器的选择与右键操作，同时不让前端替代后端授权。

## 2. 需求

- 移除文件树复选框和“删除所选”工具栏；文件详情面板不再提供绕过统一操作 API 的删除按钮。
- 文件与目录均可选：普通点击单选，Ctrl/Meta 切换选择，Shift 在当前已展开、可见的树顺序连续选择。
- 右键未选节点时先单选该节点；右键已选节点时保留选择集。菜单提供删除、移动/改路径、重命名；移动/改路径与重命名仅在 Raw hosted 显示，Maven/npm 仅显示格式感知删除。
- 删除和移动支持多项；重命名仅单项；移动和重命名仅在 Raw hosted 显示。
- 非管理员不可进入多选或危险菜单；失败不刷新树且保留选择与详情，成功后刷新并清空受影响详情。搜索视图的 Shift 范围只按当前搜索结果的可见顺序计算，懒加载树不跨未加载节点。

## 3. 设计

树展开状态上提，按当前可见节点的前序顺序计算 Shift 范围。目录递归、格式限制和权限只由后端统一操作 API 决定；前端对 Raw 传 `raw_path`，对 Maven 传逻辑根，对 npm 文件行传 typed `asset_path`，不自行从路径猜测 npm 版本或拼装裸删除路径。

## 4. 任务拆分

- [ ] 改造树选择状态、展开状态和右键菜单组件。
- [ ] 接入统一操作确认弹窗、错误展示与刷新逻辑。
- [ ] 更新 i18n、devmock 与浏览器交互测试。
- [ ] 文档同步：PRD、ARCHITECTURE、CHANGELOG。

## 5. 验收标准

- 页面不存在复选框和旧批删工具栏；Ctrl/Shift/右键选择符合定义。
- Raw 的删除、移动和单项重命名走统一 API；npm tarball/packument 删除会由 typed `asset_path` 映射为逻辑目标；Maven/npm 不显示移动/重命名。
- 非管理员无危险菜单；操作失败后树与选择保留，成功后树刷新且详情状态正确。

## 6. 风险

搜索视图与懒加载树必须分别定义可见顺序，避免 Shift 选择跨越未加载节点。
