# 功能规格：服务内置 TLS 与回源 HTTPS

> 状态：已交付@v0.8.0　·　关联 PRD：FR-131　·　分支：feature/fr131-server-tls

## 1. 背景与目标

正式站 maven.example.com 经 EdgeOne(免费版)以 HTTP 回源直连源站 50020。回源链路明文 + 源站无回源 IP 白名单(免费版无"源站防护"),目标是让 **CDN → 源站 的回源链路走 HTTPS 加密**,且不需要额外反向代理(Caddy/nginx),由服务自身内置 TLS。

阶段：P1(部署安全刚需,与 FR-130 共同构成源站访问防护)。

## 2. 需求（要什么）

- 服务内置 TLS 监听,支持 **HTTP 与 HTTPS 双监听并存**:现有 `JIAN_HTTP_ADDR`(50020 HTTP)完全不动(健康检查、主备复制、本地访问),新增独立 HTTPS 端口供 CDN 回源。
- TLS 全部经**环境变量**配置,不引入管理端 UI:
  - `JIAN_TLS_ADDR`：HTTPS 监听地址,默认 `:443`;**空 = 不启用 TLS**(默认行为不变)
  - `JIAN_TLS_CERT` / `JIAN_TLS_KEY`：PEM 证书 / 私钥文件路径
- 自签证书即可(EdgeOne 免费版回源默认不校验源站证书);文档给 openssl 生成命令(含 `maven.example.com` SAN)。
- 范围内：HTTP+HTTPS 双监听、环境变量配置、自签证书文档、EdgeOne 回源 HTTPS 部署说明。
- 不做（范围外）：证书自动签发 / 续期(Let's Encrypt 集成)、TLS 管理端配置 UI、强制 HTTPS 重定向。

## 3. 设计（怎么做）

- **config 层**(`apps/server/internal/config/config.go`)：新增三个环境变量常量与 `Config` 字段 `TLSAddr` / `TLSCert` / `TLSKey`;`Load()` 解析。
- **main 层**(`apps/server/cmd/jianartifact/main.go` `run()`)：
  - 现有 HTTP `http.Server`(50020)照旧。
  - 若 `cfg.TLSAddr != ""`:读取证书文件,`tls.LoadX509KeyPair` 校验;**校验失败 → 整体启动失败并明确报错(防静默降级)**;成功则起第二个 `http.Server`,`ServeTLS(cert, key)` 监听 TLS 端口。双服务共用同一个 `http.Handler`。
  - 拆出 `startTLSServer(handler, cfg) error` 便于测试与错误处理。
- **HTTP 处理完全复用**:TLS 与 HTTP 用同一个 `newApplicationHandler` 产出的 handler(路由、中间件、认证全一致)。
- 文档：`docs/OPERATIONS.md` 环境变量表补三行 + 自签证书生成命令 + EdgeOne 回源 HTTPS 配置步骤。

## 4. 任务拆分

- [ ] config：`JIAN_TLS_ADDR` / `JIAN_TLS_CERT` / `JIAN_TLS_KEY` 常量、字段、解析 + config_test
- [ ] main：双监听启动(证书校验失败 → 整体启动失败) + 复用同一 handler
- [ ] 文档同步：OPERATIONS.md(环境变量表 + openssl 自签命令 + EdgeOne 回源 HTTPS 步骤)、CHANGELOG
- [ ] 验证门：单测 + 真机(103 上配自签证书起 TLS,curl -k 200;EdgeOne 回源改 HTTPS 后上传 201)

## 5. 验收标准

1. 配置 `JIAN_TLS_ADDR=:8443` + 自签证书后,`curl -k https://<源站IP>:8443/readyz` → 200;同一时刻 HTTP 50020 `/readyz` 照常 200(双监听并存)。
2. `JIAN_TLS_ADDR` 为空(默认)时行为与旧版完全一致,无任何 TLS 痕迹。
3. 配置 `JIAN_TLS_ADDR` 但证书文件缺失 / 格式错误 → **整体启动失败**并输出明确错误(防静默降级);未配置 `JIAN_TLS_ADDR` → 纯 HTTP,行为不变。
4. `JIAN_TLS_ADDR=:443`(默认)未配置证书时等同未启用(不监听 443)。
5. **真机验收(需用户确认)**:EdgeOne 控制台把 maven.example.com 回源协议改为 HTTPS(443,自签证书,免费版默认不校验),回源后公网经 CDN 上传 `maven-tabooproject-release` → 201;IP 直连(伪造 Host)→ 404。主备复制(108→103)不受影响。

## 6. 风险 / 待定

- EdgeOne 免费版回源 HTTPS 是否默认不校验源站证书:已查证官方文档"默认不校验,证书校验为付费功能"——免费版可用;若实际回源失败(525/555)需在 EdgeOne 端确认。
- 双监听 = 多一个公网端口(443)暴露:TLS 加密解决明文嗅探,爆破/DoS 残余风险由登录限流与 CDN 承载(与 FR-130 Token 校验配合后,直连 443 即使伪造 Host/Token 也无法通过)。
