# 功能规格：界面语言策略与切换（i18n 落地）

> 状态：开发中　·　关联 PRD：FR-139　·　分支：dev

## 1. 背景与目标

控制台此前是**事实上的单语**：`src/i18n/index.ts` 写死 `lng: "zh"`，`en.ts` 只有 `migrations` 一个命名空间是英文（其余 23 个命名空间整体继承中文），全站没有语言切换入口、没有浏览器语言检测、也没有偏好持久化。`docs/specs/0.2.0-web-admin.md` 在立项时就把它列为「多语言英文资源与语言切换 UI」的**预留未落地**项，本规格把它闭环。

同时，界面里散落的 36 处 `"zh-CN"` 硬编码（`toLocaleString` / `Intl.DateTimeFormat` / Mantine 日期组件）让「切了语言但数字与时间仍是中文格式」，属于同一目标的另一半。

目标（FR-139）：

- 公开页面（匿名可访问的浏览路径）按**浏览器语言**自动选择中/英；
- 管理页面（需登录的功能面）**默认中文**，避免运维在熟悉的界面语言里被自动切换；
- 用户在页眉显式选择的语言**优先级最高**并跨会话记住；
- 切换即时生效，全站的时间、数字、日期格式跟随当前语言（不再硬编码 `zh-CN`）。

阶段：P2（控制台体验收敛，0.8.1 开发线）。

## 2. 需求（要什么）

**语言解析优先级**（从高到低）：

1. **用户显式选择**（页眉切换、写入 `localStorage`）——最高优先级，与所在路由无关；
2. **浏览器语言**（`navigator.languages`，取第一个可匹配项）：`zh*` → 中文，其余 → 英文；
3. **路由默认**：公开路由 → 按上一条的浏览器语言；管理路由与 `/setup` → 中文。

公开路由（按浏览器语言）：`/repositories`、`/repositories/:name`、`/search`、`/p/:name`。
管理路由（默认中文）：`/dashboard`、`/users`、`/tokens`、`/settings`、`/licenses`、`/audit-logs`、`/host-monitoring`、`/migrations*`、`/repositories/:name/acl`。

**切换入口**：

- 页眉右侧操作组新增语言切换按钮，沿用全站「图标 + 文字」口径；窄屏用既有 `HeaderIconAction`（图标 + `aria-label`），桌面用 `Button` + `leftSection` 图标。
- 点击在「中文 / English」间切换，**即时生效**（无需刷新），并写入 `localStorage` 记住选择。
- 同步 `<html lang>`（`zh-CN` / `en`），让读屏与浏览器翻译机制拿到正确语言。

**格式跟随语言**：

- 全站 36 处硬编码 `zh-CN` 改为按当前语言解析出的 BCP-47 标记（`zh-CN` / `en-US`）。
- `components/audit/labels.ts` 的 5 个**模块级** `Intl.DateTimeFormat` 常量改为按语言惰性构造并缓存——模块级常量在切语言后不会重建，是本次必须一并解决的问题。
- 未带 locale 参数的 `toLocaleString()`（10 处）同样收敛到统一入口，避免跟随浏览器 locale 而与界面语言分叉。

范围内：语言解析与缓存、页眉切换入口、`<html lang>` 同步、locale 格式化入口收敛、`/setup` 覆盖。

不做（范围外）：服务端持久化语言偏好（本轮为浏览器本地偏好）；URL 前缀式多语言路由（`/en/...`）；RTL（当前无 RTL 语言）；日期库（dayjs）locale 引入；HTML 目录索引页的多语言（该页是服务端渲染的零依赖页面，明确不做，见 E1）。

## 3. 设计（怎么做）

### 3.1 语言域模块（新增 `src/i18n/language.ts`）

把「语言是谁、从哪来、怎么记、怎么用」收敛到一个模块，避免解析逻辑散落在布局与格式化函数里：

- `type Language = "zh" | "en"`；常量 `LANGUAGE_STORAGE_KEY = "jianartifact.language"`（沿用全站 `jianartifact.*` 前缀范式）。
- `toLocaleTag(language)`：`zh` → `"zh-CN"`、`en` → `"en-US"`。**所有** `toLocaleString` / `Intl.*` / Mantine 组件 prop 的唯一取值来源。
- `resolveBrowserLanguage()`：读 `navigator.languages`（回退 `navigator.language`），`zh` 开头 → `zh`，其余 → `en`；无 `navigator`（SSR / 测试环境缺失）时回退 `zh`。
- `readStoredLanguage()` / `writeStoredLanguage()`：`localStorage` 读写，带 `try/catch`（隐私模式下可能抛异常），与 `api/client.ts`、`AuthContext` 的既有手写范式一致。
- `resolveLanguage({ pathname, stored })`：按 §2 的优先级返回最终语言；公开路由判定用**显式路径表**（`isPublicPath`），而不是「是否已登录」——匿名用户在公开页与在管理页（被 `RequireAuth` 拦下）的默认语言因此可区分。

### 3.2 应用语言（新增 `src/i18n/useLanguage.ts` + 语言格式上下文）

- `useLanguage()` 返回 `{ language, explicit, localeTag, setLanguage }`：内部把当前语言同步给 i18next（`i18n.changeLanguage`）、写 `<html lang>`、写 `localStorage`。
- 路由变化时按 §2 重算「默认语言」（仅在用户未显式选择时生效），由 `src/app/AppLayout.tsx` 内的一次 `useEffect` 挂载。
- `/setup` **不需要**额外订阅：它在初始化时由同一解析函数按路径判定（非公开 → 中文，有偏好则用偏好），且该页没有语言切换入口，运行期不会变。
- 数字 / 时间格式化统一入口：`src/i18n/current.ts` 暴露 `currentLocaleTag()` 与 `localizedFormatter()`（按 `语言|选项` 缓存 `Intl` 实例）。`src/lib/format.ts` 与 `src/components/audit/labels.ts` 改为调用它们，把 5 个模块级 `Intl.DateTimeFormat` 常量换成惰性构造——切语言后自然取到新格式器。

### 3.3 现状侵入点（改造清单）

| 位置                                                                  | 现状                          | 改法                                      |
| --------------------------------------------------------------------- | ----------------------------- | ----------------------------------------- |
| `src/i18n/index.ts`                                                   | `lng: "zh"` 写死              | 初始化时用 `resolveLanguage` 结果         |
| `src/app/AppLayout.tsx`（页眉右侧操作组、`useEffect`）                | 无语言逻辑                    | 新增切换按钮 + 路由变化重算               |
| `src/components/audit/labels.ts`（5 个模块级 `Intl.DateTimeFormat`）  | `"zh-CN"` 常量                | 按语言缓存的格式器                        |

| `src/components/observability/*`、`src/pages/*`（共 30 处运行时调用） | `"zh-CN"` 写死                | 同上                                      |

### 3.4 测试策略

- `language.ts` 的解析优先级：显式选择 > 浏览器语言 > 路由默认，覆盖 `zh-CN` / `en-US` / 无匹配语言 / `navigator` 缺失。
- 切换行为：点击页眉切换后 `i18n.language`、`<html lang>`、`localStorage`、以及一个真实格式化输出（如审计时间）四者一致。
- 守卫：`I18nKeys.test.ts`（F1 已落地）保证两种语言的键集与占位符同构，切语言后不会出现缺键回落。

## 5. 验收标准

- 解析优先级正确：清空偏好后，`en-US` 浏览器首访 `/repositories` 落英文、首访 `/dashboard` 落中文；显式选英文后访问 `/dashboard` 仍为英文（用户选择优先于路由默认）。
- 切换即时生效：点击页眉语言按钮，界面文案、`<html lang>`、时间/数字格式三者同时切换，刷新后保持。
- 格式化跟随：审计中心的时间列、仪表盘的数字与日期选择器在两种语言下的输出格式不同（不再恒为 `zh-CN` 格式）；`labels.ts` 的模块级常量切语言后不再返回旧格式。
- 键集完整：`I18nKeys.test.ts` 与 `tsc`（`satisfies Resources`）均通过，任何语言下无裸键、无缺键回落。
- 范围外不回归：`/p/:name` 别名重定向、`/setup` 自举流程、DevMock 场景参数在两种语言下行为不变。
- **真机（需用户确认）**：`en-US` 与 `zh-CN` 两个浏览器语言环境首访落点正确；切换后刷新保持。

## 6. 风险 / 待定

- **`/setup` 与布局外路由**：`/setup` 不经 `AppLayout`，语言重算必须由页面自身订阅，否则该页不跟随。已在 §3.2 明确。
- **模块级常量残留**：`labels.ts` 的 5 个常量与 10 处无 locale 参数的 `toLocaleString` 是「改了 locale 但看不出变化」的隐蔽来源，验收需逐个确认（已列入 §5）。
- **测试隔离**：`test/setup.ts` 的 `afterEach` 会 `localStorage.clear()`，语言偏好用例需自备清理；`window.matchMedia` 桩恒为桌面态，窄屏切换按钮需单独覆盖。
